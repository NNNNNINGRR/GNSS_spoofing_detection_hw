## 一、方法原理与数学定义

Hotelling T² 是多元统计过程控制（MSPC）的经典监控量，工业过程监测（化工、半导体）中应用数十年。其现代实现通常与主成分分析（PCA）结合，把"清洁正常运行"建模为一个低维线性子空间，监控量同时考察两个互补的偏离方向：

1. **得分空间（T² 统计量）**：样本在清洁主子空间内的投影位置是否偏离清洁质心。对标准化特征做 PCA，取累计方差贡献 90% 的前 $k$ 个主成分（载荷矩阵 $P_k\in\mathbb{R}^{8\times k}$，方差对角阵 $\Lambda$），得分向量 $T_t=\boldsymbol{z}_tP_k$，统计量

$$T^2_t=T_t^{\top}\Lambda^{-1}T_t=\sum_{j=1}^{k}\frac{T_{t,j}^2}{\lambda_j} ,$$

按各主成分方差加权——清洁数据方差大的主成分方向允许大偏离，方差小的方向严格。

2. **残差空间（SPE / Q 统计量）**：样本落在清洁子空间之外的能量，$\mathrm{SPE}_t=\|\boldsymbol{z}_t-P_kP_k^{\top}\boldsymbol{z}_t\|_2^2$。相关峰畸变类欺骗使特征组合偏离清洁的线性结构，能量泄漏到残差方向。

本实现的合并统计量将两项各自按训练最大值归一后相加：

$$s_t=\frac{T^2_t}{\max_{\text{train}}T^2}+\frac{\mathrm{SPE}_t}{\max_{\text{train}}\mathrm{SPE}} .$$

**与马氏距离的关系**：若保留全部主成分（$k=8$），$T^2$ 即为马氏距离平方；截断到 90% 后，T² 只管"子空间内"，SPE 管"子空间外"——等于把异常分成"清洁模式内的量变"与"清洁模式外的质变"两类证据。这一分解理论上非常适合 SQM 特征：功率阶跃是清洁模式内的强偏移（T² 捕捉），峰畸变是新模式（SPE 捕捉）。

## 二、源码解析

实现位于 `method_lib/traditional/HotellingT2_MultiVar_ProcessMonitoring.py`：

```python
def fit(self, X):
    X = np.asarray(X, dtype=np.float64)
    self.mean_ = X.mean(axis=0)
    self.std_ = X.std(axis=0) + 1e-9
    Z = (X - self.mean_) / self.std_        # 内部再次标准化
    self.pca = PCA(n_components=self.components)   # components=0.9：累计方差 90%
    self.pca.fit(Z)
    return self

def score(self, X):
    X = np.asarray(X, dtype=np.float64)
    Z = (X - self.mean_) / self.std_
    T = self.pca.transform(Z)               # 得分 [N, k]
    rec = self.pca.inverse_transform(T)     # 子空间重构
    t2 = np.sum((T / (np.std(T, axis=0) + 1e-9)) ** 2, axis=1)  # 各主成分方差加权平方和
    spe = np.linalg.norm(Z - rec, axis=1)   # 残差范数
    return t2 / (np.max(t2) + 1e-9) + spe / (np.max(spe) + 1e-9)
```

要点解析：(1) `fit` 内部又做了一次标准化，与驱动层的 z-score 级联无害（线性变换）；(2) `n_components=0.9` 让 sklearn 自动选择 $k$——本特征集清洁数据前几个主成分即覆盖 90% 方差（特征强相关），$k$ 约 3–4，残差维 4–5；(3) T² 用的是**测试批内** `np.std(T, axis=0)` 而非训练主成分方差——这是库实现的一个近似（批内方差与 $\lambda_j$ 在大样本下接近，但批内含欺骗帧时会略受污染）；(4) 归一用 `np.max`（训练调用时即训练最大值），对长尾敏感；(5) 无状态逐帧方法，t2/spe 均为逐样本计算，无需分块。

## 三、逐场景检测结果

### ds1（DS-2，简单·静态·高功率 ~10 dB）

![ds1](D:/文献复现/SQM数据集制作/exp_gnss/results/fusion/figs_scenes/HotellingT2/ds1.png)

| 指标 | 值 |
|---|---|
| ROC-AUC | 0.999 |
| TPR@1%（实际FPR） | 0.885（0.000） |
| TPR@5%（实际FPR） | 0.998（0.000） |
| TPR@10%（实际FPR） | 0.998（0.005） |
| ADD / hit | 0.04 s / 1 |

**分析**：功率阶跃同时推高 T²（子空间内强偏移）与 SPE（功率组合偏离清洁线性关系），5%/10% 档近乎满分且实际 FPR≈0。1% 档只有 0.885，低于 5% 档的 0.998——说明 1% 阈值恰好落在分数分布过渡带内，少量欺骗帧分数未越过；该现象（档间跳变）是本方法分数分布双峰结构的特征。

## 四、宏平均汇总与综合分析

| 指标 | 宏平均（8 场景） |
|---|---|
| ROC-AUC | 0.8269 |
| TPR@1% / 实际 FPR | 0.2844 / 0.0004 |
| TPR@5% / 实际 FPR | 0.3709 / 0.0044 |
| TPR@10% / 实际 FPR | 0.4205 / 0.0137 |
| ADD 命中 | 6/8 |

**综合分析**：(1) 本方法是全部方法中**虚警最守纪律**的（三档实际 FPR 0.0004/0.0044/0.0137，均低于名义值），归功于 max 归一+双统计量的保守设计；(2) 但检出全面偏低（宏 1% 档 0.284），且呈现鲜明的"场景选择性"：对时间调整类（ds7/ds8）与高功率（ds1）可用，对畸变类（ds2/ds3/ds6）与动态（ds4/ds5）失明；(3) 失明机理值得写入论文——**PCA 方差加权把"训练方差大"的方向当作正常方向宽容处理，而欺骗恰恰可以利用这些方向**（匹配功率攻击主打的畸变特征方差大、动态场景运动方向方差大）；(4) 与 Mahalanobis（全空间 T²）对比：保留全部主成分的版本（AUC 0.948）显著优于 90% 截断版（0.827），说明在本 8 维小特征集上，截断子空间损失的信息大于抗噪收益——这也是 PCA 型监控适用于高维（几十维以上）而低维宜用全协方差的实证依据。
