# 07 kNN 距离（k=5）——方法详解与逐场景结果

> 系列文档之七。协议同前：v3.1 八维特征、cs+cd 清洁训练、清洁分位三档阈值（1%/5%/10%）、逐帧判决。
> 表格数值与 `results/fusion/single_KnnDist/metrics.csv` 一致。本方法为本研究自建的非参数基线，
> 最终宏平均检出为全部"库版"方法最高。

## 一、方法原理与数学定义

k 近邻距离检测是把"清洁总体分布偏离度"非参数化的最直接方式：以整个清洁训练集 $\mathcal{D}$（45476 帧）为参照库，计算测试帧到库中最近 $k$ 个样本的平均欧氏距离：

$$s_t=\frac{1}{k}\sum_{i=1}^{k}\big\|\boldsymbol{z}_t-\boldsymbol{z}_{(i)}\big\|_2,\qquad k=5,\quad \boldsymbol{z}_{(i)}\in\mathcal{D} .$$

距离大 ⇔ 测试帧落在清洁样本稀疏的区域 ⇔ 偏离清洁分布。它与参数族构成一条清晰的方法谱系：马氏距离假设高斯并用 $\Sigma^{-1}$ 加权；kNN 距离不做任何分布假设，用样本几何直接刻画密度（$\hat{p}(\boldsymbol{z})\propto 1/r_k^d$，$r_k$ 为第 $k$ 近邻距离）；LOF 再进一步用"邻域密度比"做局部归一。

**优点**：(1) 零假设——清洁分布多峰（cs/cd 两簇）、弯曲、重尾均可表达；(2) 单调性直接——分数就是到"正常"的物理距离，可解释性强（阈值 $\tau$ 的含义即"离最近的正常样本至少多远"）；(3) 对逐帧独立异常稳健（k=5 平均掉单点抖动）。**代价**：(1) 参照库的采样密度直接影响距离分布——cs 簇样本多、cd 簇样本少时，cd 一侧的测试帧天然距离偏大，造成系统性虚警偏置（实测动态场景实际 FPR 偏高的根源）；(2) 推理需近邻搜索（45k×8 维，KD-tree 退化为暴力时约 $O(Nd)$ 每帧，实测整测试集数秒）。

## 二、源码解析

实现为 `run_fusion_v31.py` 中的自建类：

```python
class KnnDist:
    def __init__(self, k=5):
        self.k = int(k)

    def fit(self, X):
        self.nn = NearestNeighbors(n_neighbors=self.k, n_jobs=-1).fit(X)
        return self          # "训练" = 建立近邻索引（sklearn 自动选树/暴力）

    def score(self, X):
        X = np.asarray(X)
        out = np.empty(len(X))
        for i in range(0, len(X), 20000):        # 分块查询防止距离矩阵爆内存
            out[i:i + 20000] = self.nn.kneighbors(X[i:i + 20000])[0].mean(axis=1)
        return out   # 每块返回 (距离, 索引)，取距离的按行均值 = s_t
```

要点解析：(1) `fit` 只建索引不压缩数据——kNN 是"惰性学习器"，45476 帧参照库原样保留在内存（约 3 MB，可部署于接收机固件）；(2) `kneighbors` 默认 `n_neighbors=5`，返回矩阵 `[块大小, 5]` 的距离，`mean(axis=1)` 即统计量；(3) 分块 20000 是工程折衷：暴力搜索的成对距离块约 $20000\times45476\times8\text{B}\approx7$ GB（float64），分块后数百 MB、可并行（`n_jobs=-1`）；(4) `n_jobs` 利用全部核心，176799 帧打分实测秒级；(5) 无状态逐帧方法，与序列方法无分块问题。

**分析**：功率阶跃使样本远离一切清洁样本，$r_5$ 巨大——三档 0.998+，ADD 0.04 s。但注意实际 FPR：1% 档已 0.019（约 2 倍名义值）、10% 档 0.307——**kNN 分数的清洁长尾在静态段也存在**（清洁采样密度的空隙被分位阈值截出的位置不同），其阈值迁移比马氏距离（同场景 1% 档实际 0.000）松。这是密度型方法的共同税。
