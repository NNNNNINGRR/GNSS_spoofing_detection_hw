## 一、方法原理与数学定义

StatisticalThreshold 是单类异常检测中最朴素的参量化基线：假设"清洁数据的每个特征围绕其均值呈高斯波动"，任何帧只要在任一特征上偏离清洁均值过远即判为异常。对每个特征 $f\in\{1,\dots,8\}$，用清洁训练集估计均值 $\mu_f$ 与标准差 $\sigma_f$，逐帧计算标准化偏离的绝对值：

$$z_{f,t}=\frac{\left|x_{f,t}-\mu_f\right|}{\sigma_f},$$

检测统计量取全部特征 z 分数的算术平均：

$$s_t=\frac{1}{F}\sum_{f=1}^{F} z_{f,t},\qquad F=8 .$$

告警规则为 $s_t\ge\tau_\alpha$，$\tau_\alpha$ 为清洁训练分数的 $(100-\alpha)$ 分位。

**方法蕴含的两个强假设与代价**：其一，"各特征独立"。实际 SQM 指标强相关（m_ratio 与 m_delta 近似线性相关、双 delta 与 delta 部分共线），求和相关特征等于重复计分，分数方差被放大；其二，"偏离方向一致、幅度同量级"。GNSS 欺骗恰恰常表现为个别特征的强偏离（高功率攻击时 received_power/CN0 独自跳变 10 dB 以上，其余特征几乎不动），此时平均把单特征异常稀释 $F=8$ 倍——若只有 1 个特征达到 $z=8$，均值仅 1.0，淹没在其余 7 个特征的噪声（期望约 0.8）里。

**本研究的定位**：它回答的问题是"多特征联合检测若做得正确，收益至少应比平均 z 高多少"。实测宏平均 AUC 0.940、1% 档 TPR 0.697@实际 FPR 0.005——作为"便宜但粗糙"的下界参照表现合格，也清楚暴露了平均聚合的稀释效应。

## 二、源码解析

实现位于 `method_lib/traditional/StatisticalThreshold_SingleVar_Gaussian.py`，核心两段：

```python
def fit(self, X):
    X = np.asarray(X, dtype=np.float64)
    self.mean_ = X.mean(axis=0)            # 逐特征均值 μ_f
    self.std_ = X.std(axis=0) + 1e-9       # 逐特征标准差 σ_f（防零）
    self.q1_ = np.percentile(X, 25, axis=0)  # IQR 模式用
    self.q3_ = np.percentile(X, 75, axis=0)
    return self

def score(self, X):
    X = np.asarray(X, dtype=np.float64)
    if self.method == "zscore":
        s = np.abs((X - self.mean_) / self.std_)   # |z| 矩阵 [N, F]
    else:  # "iqr"
        iqr = (self.q3_ - self.q1_) + 1e-9
        s = np.maximum((self.q1_ - X) / iqr, (X - self.q3_) / iqr)
    return s.mean(axis=1) if X.ndim == 2 else s    # 平均聚合 → 检测分数
```

要点解析：(1) `fit` 只接收清洁训练数据，统计量 `mean_/std_` 完全来自 cs+cd，测试阶段零泄漏；(2) `score` 先算 $|z|$ 再 `mean(axis=1)`，正是"平均聚合"发生稀释的位置——若改为 `max(axis=1)` 即变为 StatZ 的均值-标准差版；(3) 库内还提供 IQR 模式（以四分位距为尺度，对重尾更稳健），本实验采用默认 zscore 模式，因清洁特征近似对称分布；(4) 输入为 z-score 标准化后的特征（驱动脚本统一用训练统计做标准化），故方法内部的 $\mu_f,\sigma_f$ 实为"标准化后清洁分布"的中心与尺度，等价于再一次精细修正。该方法为无状态逐帧方法，无需分块处理。
