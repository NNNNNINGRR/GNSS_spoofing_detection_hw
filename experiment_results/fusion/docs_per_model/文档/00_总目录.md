# 传统算法 × 融合：逐方法详解文档——总目录

**系列定位**：论文准备稿。每个方法独立成篇（原理与数学公式 → 源码解析 → 八个场景各自的图片+完整指标表+分析 → 宏平均汇总与综合分析），终篇为融合算法。全部数值直接取自 `results/fusion/{single_*,or3_*}/metrics.csv`，全部图片为绝对路径引用（`figs_scenes/<方法>/ds<i>.png`，融合另用 `scenes/`），可用任何 Markdown 工具渲染。

## 统一实验协议（各篇不再重复细节）

- **数据血缘**：TEXBAT 全 10 场景 → 改造版 GNSS-SDR（212 字节 dump）解算（**原始解算 v3.1_old，2026-08-18 批次**）→ `build_metrics.py` 50 Hz 逐帧 8 维特征（±0.5 chip 口径 + 双 delta）→ `make_datasets.py` 构建训练/测试集；
- **训练**：仅 cs+cd（45476 帧，纯清洁，零日协议）；**测试**：ds1–ds8（176799 帧，欺骗帧 76.8%），逐帧判决；
- **标准化**：z-score（训练统计）；序列型方法按 cs/cd 块与场景块分段打分；
- **阈值**：清洁训练分数 p99/p95/p90（名义虚警 1%/5%/10%），报告 `tpr@cfX`（工作点检出）与 `rfpr@X`（同阈值实际虚警）成对；
- **场景映射**：本地 dsN = TEXBAT DS-(N+1)；动态 = ds4/ds5；sophisticated = ds6；位置推送 = ds3。

## 阅读建议（写论文时的取材路径）

1. **方法章**：15/16（改进）+ 17（融合）为核心；01/03/07/11/12 作代表性基线；02/05 作 MSPC 族对照；
2. **实验章主表**：上表（或其精简版）+ 融合篇的逐场景表；
3. **讨论章素材**：四个反面案例（04 MCD 标定错配、06 STL 范式不匹配、13 StatZ 尺度饱和、14 条件变量污染）+ 08 LOF 的"名义 vs 实际 FPR"教训 + 10 IF 的档间跳变现象；
4. **消融链**：12（库版 CUSUM）→16（MCUSUM）单变量对照；11（EWMA）→15（MEWMA）单变量对照；17 篇内 mean/median vs or3 的反面对照。
