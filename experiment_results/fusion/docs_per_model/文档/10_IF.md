## 一、方法原理与数学定义

孤立森林（Isolation Forest, Liu, Ting & Zhou, ICDM 2008 / TKDD 2012）基于一个与密度/距离完全不同的异常定义：**异常样本"少而不同"，在随机划分空间中更容易被孤立**。每棵树随机选特征、随机选切分值递归二分数据，直到叶子单点或高度上限；异常样本平均需要更浅的树即被单独隔出。样本的孤立难度由集成平均路径长度 $E[h(\boldsymbol{z})]$ 度量，异常分数经归一化：

$$s_t=-\,2^{-E[h(\boldsymbol{z}_t)]/c(n)},\qquad c(n)=2H(n-1)-\frac{2(n-1)}{n}\ (\text{BST 平均路径长度}),$$

取负号使"越大越异常"统一到全库口径。$s\to 1$：路径极短（易孤立，强异常）；$s\to 0$：路径极长（难孤立，深埋分布内部）。本文配置：200 棵树、默认子采样 256 点/树。

**与密度/距离方法的本质区别**：IF 的"正常区域"由**随机切分的几何并集**隐式定义，不做任何分布或距离计算——这带来三点特性：(1) 训练/推理极快（线性复杂度、子采样防过拟合）；(2) 对高维、非线性、重尾稳健（无距离集中问题）；(3) **对"总体连续漂移"钝感**——若全部异常样本彼此相似且数量不少（欺骗段 1.5 万帧），随机切分会为它们建立自己的叶子区域，孤立难度并不高。IF 擅长"点状离群"，不擅长"整体搬家"，这正是 SQM 欺骗检测需要验证的边界。

## 二、源码解析

实现位于 `method_lib/traditional/IsolationForest_MultiVar_NonGaussian.py`：

```python
class IsolationForest_MultiVar_NonGaussian:
    def __init__(self, contamination=0.01, n_estimators=200, seed=0):
        ...
    def fit(self, X):
        self.clf = IsolationForest(
            n_estimators=self.n_estimators,   # 200 棵
            contamination=self.contamination, # 仅影响内部 offset_（二值 predict 用）
            random_state=self.seed, n_jobs=-1)
        self.clf.fit(np.asarray(X, dtype=np.float64))
        return self

    def score(self, X):
        # score_samples 越大越正常（近似 -s 上文定义），取负使"越大越异常"
        return -self.clf.score_samples(np.asarray(X, dtype=np.float64))
```

要点解析：(1) `score_samples` 返回 sklearn 的归一化孤立分（$-2^{-E[h]/c}$ 的线性变体），取负统一方向；(2) `contamination=0.01` 不影响连续分数，仅决定内部 `offset_`——阈值标定仍由清洁分位驱动，口径与其他方法一致；(3) 每棵树子采样 256 点（sklearn 默认 `max_samples="auto"`），45k 训练集被 200 棵树覆盖多次，训练秒级；(4) 推理是 200 棵树各走一条根-叶路径取平均——单帧微秒级，**全部方法中推理最快**，嵌入接收机固件零压力；(5) 无状态逐帧方法。

## 三、逐场景检测结果

### ds1（DS-2，简单·静态·高功率 ~10 dB）

![ds1](D:/文献复现/SQM数据集制作/exp_gnss/results/fusion/figs_scenes/IF/ds1.png)

| 指标 | 值 |
|---|---|
| ROC-AUC | 0.997 |
| TPR@1%（实际FPR） | 0.313（0.000） |
| TPR@5%（实际FPR） | 0.958（0.011） |
| TPR@10%（实际FPR） | 0.998（0.037） |
| ADD / hit | 0.16 s / 1 |

**分析**：功率阶跃样本远离一切清洁叶区，孤立容易——但分数上限受"孤立深度离散化"限制：1% 档只放行 0.313，5% 档跳到 0.958、10% 档 0.998。这种**档间跳变**是 IF 的标志：路径长度的离散分布使分数呈台阶状，阈值微移引起 TPR 跳档。虚警纪律极好（三档 0.000/0.011/0.037）。

## 四、宏平均汇总与综合分析

| 指标 | 宏平均（8 场景） |
|---|---|
| ROC-AUC | 0.8779 |
| TPR@1% / 实际 FPR | 0.3101 / 0.0046 |
| TPR@5% / 实际 FPR | 0.5458 / 0.0335 |
| TPR@10% / 实际 FPR | 0.6469 / 0.0793 |
| ADD 命中 | 8/8 |

**综合分析**：(1) **虚警纪律全场最佳之一**（1% 档实际 0.005，仅次于 Hotelling/MCUSUM），但 1% 档检出仅 0.310——"台阶卡工作点"是主因：随机切分的离散化让分数分布出现平台，清洁分位标定的阈值落在平台内侧；(2) 5%/10% 档检出回升至 0.55/0.65，但仍落后密度族 0.30+——**集群式异常 + 稳态欺骗**两个结构性弱点在 SQM 任务上均被触发；(3) 速度优势数据：训练 4 s、测试 176k 帧 2 s（单线程），比 OCSVM 快两个数量级——若任务只需粗筛（高召回低精度预筛 + 慢方法复核的级联架构），IF 是合理的前级；(4) 论文定位：作为"孤立范式 vs 密度/距离范式"的对照点，其"档间跳变"现象值得在讨论章节展示（随机切分离散化的可见后果）；(5) 未进入融合委员会。
