# 16 MCUSUM（逐特征双边 CUSUM 取最大，改进②）——方法详解与逐场景结果

> 系列文档之十六。协议同前：v3.1 八维特征、cs+cd 清洁训练、清洁分位三档阈值（1%/5%/10%）、逐帧判决。
> 表格数值与 `results/fusion/single_MCUSUM/metrics.csv` 一致。本方法为**改进②**（文献依据：
> Woodall & Ncube 1990 多元 CUSUM 思路），**AUC 全场最高（0.9919）、实际虚警全场景为零**，
> 是位置推送场景（ds3）的破局方法，并进入最终融合委员会。

## 一、方法原理与数学定义

MCUSUM 把库版 CUSUM 的"先均值后累积"反转为"先累积后取最大"：对每个特征独立维护双边累积量（$k=0.5$ 为容许带，$h=5$ 为决策门限）：

$$C^{+}_{f,t}=\max\!\big(0,\ C^{+}_{f,t-1}+z_{f,t}-k\big),\qquad
C^{-}_{f,t}=\max\!\big(0,\ C^{-}_{f,t-1}-z_{f,t}-k\big),\qquad f=1,\dots,8,$$

$$s_t=\max_{f}\ \frac{\max\big(C^{+}_{f,t},\ C^{-}_{f,t}\big)}{h}.$$

**改进依据（针对库版 CUSUM 的均值聚合缺陷）**：

1. **方向抵消**：库版累积 $\bar z_t$（8 维均值）——欺骗引发的偏移方向异号（received_power/CN0 上升、m_ratio/m_delta 下降），$\bar z$ 中正负相消，可用漂移量被削去大半。逐特征累积保留每个特征各自的全部漂移证据，max 聚合取出最强证据，不受异号抵消影响。
2. **漂移的稀疏性**：GNSS 欺骗的签名天然集中在个别特征族（位置推送→码相位族 2–3 个特征；功率攻击→功率族 2 个特征）。"任一特征持续漂移即可疑"比"全体特征平均漂移才可疑"更贴合物理。Woodall & Ncube (1990) 提出对多维各自做 CUSUM 并监控其最大值（或最早越限者），正是该思想的经典形式。
3. **保留 CUSUM 的全部优点**：max(0,·) 重置对短时波动免疫（虚警纪律）、累积深度无界（对任意慢漂移按 $\sqrt{n}$ 信噪比增益收敛到检出）——这两条正是 EWMA（记忆有限）与逐帧方法（无累积）所缺。

**代价**：多重检验使整体虚警率按特征数放大（8 个并行 CUSUM 同时监控）——本文由清洁分位统一标定阈值自然吸收该效应；对"全部特征同步小幅漂移"的情形，max 不如 Mahalanobis 型的联合度量（融合互补点）。

## 二、源码解析

实现为 `run_fusion_v31.py` 中的自建类：

```python
class MCUSUM:
    """逐特征双边 CUSUM 取最大（Woodall & Ncube 1990 思路）。"""
    def __init__(self, k=0.5, h=5.0):
        self.k, self.h = float(k), float(h)

    def _run(self, Z):
        cp = np.zeros(Z.shape[1])        # 各特征 C⁺（每段起点归零）
        cm = np.zeros(Z.shape[1])        # 各特征 C⁻
        s = np.empty(len(Z))
        for i in range(len(Z)):
            cp = np.maximum(0.0, cp + Z[i] - self.k)   # 逐特征递推（向量化 8 维）
            cm = np.maximum(0.0, cm - Z[i] - self.k)
            s[i] = np.maximum(cp, cm).max() / self.h   # 跨特征取最大 / h 归一
        return s

    def fit(self, Z):
        return self        # 无需训练参数（标准化在驱动层完成）

    def score(self, Z):
        return self._run(np.asarray(Z, dtype=np.float64))
```

要点解析：(1) 与库版 CUSUM 的代码差异只在两处——递推行从"标量 $\bar z$"变为"8 维向量 $\boldsymbol{z}_t$"，输出从标量累积变为 `np.maximum(cp, cm).max()`——最小改动的消融对照；(2) `fit` 为空：方法无参数需从数据估计（k、h 为设计参数），标准化完全交给驱动层；(3) 递推每帧一次 8 维向量运算，176k 帧约 1 s；(4) 每段（cs/cd/各场景）从零状态起算——驱动层分块调用；(5) `/h` 归一使分数≈"越限倍数"，可解释性强（>1 即超过经典 SPC 决策门限）。

**综合分析**：(1) **"排序 × 纪律"双冠军**：AUC 0.9919 全场最高（六场景满分）、三档实际 FPR 全场景精确为零（约 4.4 万清洁帧无一次误报）——max(0,·) 重置 + 逐特征累积的组合在真实数据上兑现了序贯检测的理论承诺；(2) **检出结构呈"阶梯型"**：三档 TPR 几乎相同（0.875/0.909/0.916），因为累积量一旦越过清洁分位（p99 与 p95 接近，重置机制使清洁分数分布紧致）就深陷限外——**阈值档位对 MCUSUM 几乎不敏感**，这使其在融合中的 margin 表现极稳定；(3) 弱点唯一且明确：**动态强噪声下的重置拖慢首报**（ds4 ADD 96 s、ds7 ADD 122 s）——由融合的 EWMA 通道补齐（0.04 s / 51.96 s）；(4) 消融证据链完整：库版 CUSUM（均值聚合）宏 1% 档 0.744 → MCUSUM 0.875，ds3 0.284→0.919，ds6 0.583→0.939——"聚合方式"单变量改动带来的提升横跨最难两类场景；(5) 计算成本：递推 8 维向量、毫秒级，k/h 未调参（SPC 惯例值即达上述结果，调优空间留作后续）。
