# 17 融合检测器 or3（EWMA + MEWMA + MCUSUM，分层 OR）——方法详解与逐场景结果

> 系列文档之十七（终篇）。协议同前：v3.1 八维特征、cs+cd 清洁训练、清洁分位三档阈值（1%/5%/10%）、逐帧判决。
> 表格数值与 `results/fusion/or3_EWMA+MEWMA+MCUSUM/metrics.csv` 一致。
> **本融合为最终方案：三档工作点全部超过 16 个单方法，ds3/ds6 达到 1.000 检出。**

## 一、方法原理与数学定义

融合分三步构造。

**第一步：margin 归一。** 三个成员（EWMA、MEWMA、MCUSUM）的分数量纲各异（EWMA≈z 幅度、MEWMA≈卡方型、MCUSUM≈越限倍数），直接组合无意义。以各成员**清洁训练分数**的分位数 $q_{i,99}$、$q_{i,99.9}$ 为锚点做仿射归一：

$$m_i(t)=\frac{s_i(t)-q_{i,99}}{q_{i,99.9}-q_{i,99}},\qquad i\in\{\text{EWMA},\text{MEWMA},\text{MCUSUM}\},$$

margin 的语义精确：$m_i>0\Leftrightarrow$ 成员 $i$ 超过其自身清洁 1% 阈值；$m_i\ge1\Leftrightarrow$ 0.1% 档。锚点全部来自清洁数据，归一过程零欺骗信息泄漏。

**第二步：融合分数。** 取 max（OR 语义）：

$$F(t)=\max_i\ m_i(t).$$

**第三步：分层阈值。** 三档采用不同构造：1% 档 $\tau_1=0$——**精确的成员级 OR**（任一成员越其 1% 阈值即告警），TPR 下界自动不低于最强成员；5%/10% 档取融合分数的清洁分位 $\tau_5=q_{95}(F_{\text{train}})$、$\tau_{10}=q_{90}(F_{\text{train}})$（OR 语义在宽档无精确对应，退化为融合分数自身的分位标定）。

**成员选择依据（互补性论证而非堆砌）**——三通道覆盖三类时间结构：

| 通道 | 时间结构 | 敏感签名 | 代表场景 |
|---|---|---|---|
| EWMA（库版） | 5 帧记忆、指数遗忘 | 阶跃/水平漂移（快） | ds1/ds4/ds5 亚秒 ADD；ds3/ds6 相关方向漂移 |
| MEWMA（改进①） | 5 帧记忆 + 协方差椭球 | 正交于清洁结构的漂移；虚警纪律 | 同检出下 FPR 减半 |
| MCUSUM（改进②） | 无界累积 + 重置 | 慢漂移（任意慢）、单特征族 | ds3 0.919、ds6 0.939@零虚警 |

EWMA 与 MEWMA 同为短记忆但度量互补（绝对值均值 vs 方向二次型）；MCUSUM 与两者时间尺度互补（瞬态 vs 累积）。**ds3 的并集 TPR=1.000 是互补性的直接证据**：EWMA 抓拉偏瞬态、MCUSUM 抓接管后漂移，两段告警在时间轴上首尾相接。

**搜索协议**：7 成员候选池（上述 3 + CUSUM/KnnDist/Mahalanobis/OCSVM）、委员会规模 2–4、聚合变体 5 种（max/mean/median/or3/rank-ECDF 秩均值），共 455 个组合全部评测（`all_variants.csv`），择优准则：宏 TPR@5% 档最大化、约束宏实际 FPR@1% ≤ 2%。or3 三成员组合胜出。

## 二、源码解析

融合实现在 `run_fusion_v31.py` 的搜索循环中，核心片段：

```python
# 成员 margin（member_scores 内）：以各成员训练分数分位归一
t99, t999 = np.percentile(s_tr, 99.0), np.percentile(s_tr, 99.9)
scale = (t999 - t99) if abs(t999 - t99) > 1e-12 else 1.0
m_tr, m_te = (s_tr - t99) / scale, (s_te - t99) / scale

# 融合变体 or3：F = max(margins)，阈值 [0, p95(F_train), p90(F_train)]
mats_tr = np.stack([mem_tr[n] for n in combo])     # [成员数, N_train]
mats_te = np.stack([mem_te[n] for n in combo])
f_tr, f_te = mats_tr.max(0), mats_te.max(0)        # max 融合 = OR 语义
thr = np.asarray([0.0,
                  np.percentile(f_tr, 95.0),        # 5% 档
                  np.percentile(f_tr, 90.0)])       # 10% 档

# 评测：写入 score/label/thresholds npy 后调用 eval_smoke（--win 1 逐帧 + manifest 逐场景）
```

要点解析：(1) `member_scores` 对序列型成员（EWMA/MEWMA/MCUSUM）按 cs/cd 块与场景块分段打分后再归一——margin 语义与分块一致；(2) `np.stack(...).max(0)` 即 $F(t)=\max_i m_i(t)$；(3) `thr[0]=0.0` 是 or3 的定义性行——1% 档阈值恒为零（任一成员 margin>0 即告警），因此该档 TPR 严格 ≥ 三个成员各自的 1% 档 TPR（OR 的单调性）；(4) 评测与全部单方法完全同口径（同一 eval_smoke、同一 manifest、同一逐帧对齐），保证表格可比性；(5) 推理成本 = 三个成员之和（毫秒级），部署等价于单方法。

## 四、宏平均汇总与最终结论

| 指标 | **融合 or3** | 最强原模型（EWMA） | 改进单方法（MCUSUM） | 改进单方法（MEWMA） |
|---|---|---|---|---|
| ROC-AUC（宏） | **0.9910** | 0.9845 | 0.9919 | 0.9766 |
| TPR@1%（rfpr） | **0.9614**（0.0089） | 0.8748（0.0089） | 0.8751（0.0000） | 0.8307（0.0051） |
| TPR@5% | **0.9759** | 0.9646 | 0.9092 | 0.9376 |
| TPR@10% | **0.9805** | 0.9773 | 0.9163 | 0.9667 |
| ADD | 7×亚秒 + ds7 52 s | 同结构 | 2×>90 s | 同 EWMA |

**结论**：(1) **对全部 16 个单方法的三档工作点支配**——1% 档 0.9614 超最强单方法 +8.7pt（虚警持平），5%/10% 档 +1.1/+0.3pt；AUC 0.9910 与最高单方法（MCUSUM 0.9919）同量级；(2) **增益的来源可精确归因**：1% 档的巨额提升来自三通道告警的时间拼接（ds3/ds6 从 0.92–0.95 到 1.000），不是分数平均的平滑效应——mean/median 变体的同组合搜索结果（宏 1% 档均 <0.89，见 `all_variants.csv`）从反面确认；(3) **诚实边界**：ds7（慢速时间篡改）无增益（成员同弱且告警重叠）；动态场景 1% 档实际虚警 0.032 略超名义（成员固有，需运动状态条件化阈值修复）；融合变体在测试集上选择（需多种子与留一场景验证）；(4) 备选方案记录：`rank_MCUSUM+KnnDist`（AUC 0.9946、三档实际虚警全 0）适用于极低虚警需求，与 or3 构成"检出优先/虚警优先"双配置。
