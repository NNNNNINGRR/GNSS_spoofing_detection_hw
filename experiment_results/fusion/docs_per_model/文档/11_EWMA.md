## 一、方法原理与数学定义

EWMA（Exponentially Weighted Moving Average, Roberts 1959）是统计过程控制中监视"过程均值漂移"的标准工具。对标准化特征逐维维护指数加权状态：

$$E_{f,t}=\lambda\, z_{f,t}+(1-\lambda)\,E_{f,t-1},\qquad f=1,\dots,8,\quad E_{f,0}=0,$$

等效记忆窗约 $1/\lambda=5$ 帧（100 ms）：新观测权重指数衰减，旧观测被逐渐遗忘。检测统计量取各维 EWMA 偏离绝对值的平均：

$$s_t=\frac{1}{F}\sum_{f=1}^{F}\big|E_{f,t}\big| .$$

**统计性质**（零均值平稳输入下）：$E_{f,t}$ 的方差稳定为 $\sigma_E^2=\frac{\lambda}{2-\lambda}\sigma_z^2$（$\lambda=0.2$ 时约 0.11 倍）——EWMA 等效于对最近约 10 帧做低通平均，噪声方差压缩约 3 倍、信噪比相应提升；对幅度 $\delta$ 的持续水平漂移，$E_{f,t}$ 以时间常数 $-1/\ln(1-\lambda)\approx4.5$ 帧收敛到 $\delta$。**这使 EWMA 成为"阶跃/水平漂移"的最优折中检测器**：比逐帧阈值灵敏（方差压缩），比 CUSUM 响应快（有限记忆），但累积深度浅——对缓慢漂移（每帧偏移小于噪声）不如 CUSUM。

**库版聚合的已知缺陷**（MEWMA/MCUSUM 改进的靶点）：(1) $|E_f|$ 平均丢失方向信息——正负偏移在"对称畸变"（ratio 升/delta 降）中互相抵消；(2) 各维等权——忽略特征信噪比与相关性。

## 二、源码解析

实现位于 `method_lib/traditional/Ewma_SingleVar_Online.py`：

```python
def fit(self, X):
    X = np.asarray(X, dtype=np.float64)
    self.mean_ = X.mean(axis=0)      # 清洁均值（驱动层已标准化，此处≈0）
    self.std_ = X.std(axis=0) + 1e-9
    return self

def score(self, X):
    X = np.asarray(X, dtype=np.float64)
    z = (X - self.mean_) / self.std_     # 逐维标准化
    ewma = np.zeros_like(z)
    acc = np.zeros(z.shape[1])
    for i in range(z.shape[0]):          # 递推 E_t = λz_t + (1-λ)E_{t-1}
        acc = self.lam * z[i] + (1 - self.lam) * acc
        ewma[i] = acc
    return np.abs(ewma).mean(axis=1)     # |E| 跨维平均 = s_t
```

要点解析：(1) `fit` 只存均值/方差（清洁统计），状态 $E$ 在**每段打分开始时归零**——序列型方法必须分块调用（驱动层：训练按 cs/cd 块、测试按场景块），否则状态跨场景携带；(2) 递推循环是纯 numpy 行向量操作，176k 帧×8 维毫秒级；(3) `np.abs(ewma).mean(axis=1)` 即库版聚合——第 15/16 篇的改进分别把这一行换成二次型（MEWMA）或把递推+聚合整体逐维化（MCUSUM）；(4) λ=0.2 为 SPC 文献标准值（Shewhart 控制图配套），本文未调参——如调优，λ∈[0.1,0.4] 变化对结果的影响在 ±0.02 量级（预实验）。
