# 第 0 篇：基础概念——欺骗、特征、单类检测、指标

> 阅读目标：读完本篇，你能看懂后面所有方法的输入、输出和评测表。
> 本文假设你**没有接触过** GNSS 接收机、也没有接触过统计假设检验。

## 0.1 GNSS 欺骗攻击是什么

GPS/GNSS 接收机靠接收卫星信号计算位置和时间。**欺骗攻击（spoofing）**是：攻击者用一台发射机，发射一套"看起来像真的"卫星信号，把接收机"骗"到错误的位置或时间上。

攻击的物理过程（这是理解一切特征的钥匙）：

1. **同步**：攻击者先发射与真实信号功率相近、码相位略滞后的假信号；
2. **拉偏（pull-off）**：假信号逐步加速、把接收机的跟踪环路从真实信号"拖"到假信号上——这个过程中，接收机内部的相关峰被拉扯、变形；
3. **接管（takeover）**：假信号完全占据跟踪环路，接收机从此锁在假信号上，但自己浑然不知。

**为什么危险**：接收机一旦被接管，报出的位置/时间就是攻击者想让你看到的。所以检测必须在**接管完成之前或之中**发生——这决定了"检测要多快"（见 0.4 的 ADD 指标）。

## 0.2 我们用什么特征检测

接收机内部有个**跟踪环路**，它在不停地算"本地复制的码和收到的信号有多对齐"。关键输出是一组**相关器**（correlator）：提前（Early）、即时（Prompt）、滞后（Late）等不同码相位处的 I/Q 幅度。

**欺骗会扭曲相关峰的形状**：拉偏时峰被拉歪、接管后峰的位置和形状变了。于是我们把相关器的输出加工成 8 个"指纹"特征（每 20 毫秒一帧，即 50 Hz）：

| 特征 | 通俗解释 | 欺骗时会发生什么 |
|---|---|---|
| m_ratio | 早+晚 除以 即时 | 峰变宽/变窄时偏离 1 |
| m_delta | 早−晚 除以 即时 | 峰不对称时偏离 0 |
| m_elp | 早与晚的相位差 | 两臂相位不一致时变大 |
| m_symdiff | 早−晚的复幅度，除以噪声尺度 | 对称性破坏的"信噪比"版本 |
| m_manfredini | 用 9 个更细的相关器量峰的内部变形 | 细粒度畸变最敏感 |
| m_dd | 双 delta：宽对减窄对 | 峰曲率变化的专门探测器 |
| received_power | 信号功率（相对基线） | 高功率攻击时跳变 |
| CN0 | 载噪比 | 同上 |

**关键直觉**：正常接收时这 8 个特征在某个"正常范围"里小幅波动（噪声）；欺骗时它们会**偏离正常范围**。检测的任务就是：给每个时刻的 8 维向量判"正常"还是"异常"。

> 注意 m_dd（双 delta）的来历：Pirsiavash et al. (2017) 发现，把"宽间距的早晚差"减去"窄间距的早晚差"，能专门放大相关峰**曲率**的变化，而曲率是拉偏时最先变的东西。

## 0.3 单类异常检测：为什么只用正常数据训练

这是个关键设计决策。如果你训练一个分类器区分"正常 vs 欺骗"，你需要**覆盖所有可能的欺骗样本**——但攻击方式无穷无尽（高功率、匹配功率、位置推送、载波对齐……），总会有你没见过的。

**单类检测（one-class / zero-day）**换个思路：

> **我只学"正常"长什么样，然后宣布：一切不像正常的都是可疑的。**

就像只见过健康体检报告的人，也能看出"这份报告不对劲"——不需要先见过所有疾病。

所以实验协议是：
- **训练**：只用 cs 和 cd 两个**干净**场景（45476 帧，无欺骗）；
- **测试**：8 个欺骗场景（176799 帧）全部拿来"考"；
- 训练时**绝不接触**欺骗数据（这叫零日协议，也是 Paper A：Iqbal 2024 的设定）。

## 0.4 指标怎么看（这是你读所有表格前必须先会的）

每个方法输出一个**异常分数** $s_t$（越大越可疑），然后和一个**阈值** $\tau$ 比较：$s_t\ge\tau$ 就报警。

**两个最重要的概念：**

1. **名义虚警率 vs 实际虚警率**。我们规定阈值 = 训练（正常）分数的某个分位，比如第 99 分位 $q_{99}$——意思是"正常数据里只有 1% 会超过这个阈值"，这就是**名义虚警率 1%**。但拿到测试场景上，攻击前的正常段里到底有多少帧超过阈值？这个实测比例叫**实际虚警率（rfpr）**。如果实际 > 名义，说明阈值"迁移"不好（测试环境的正常波动比训练大）。
2. **检出率（TPR）**：欺骗帧里有多少被正确报警。`tpr@cf1%` = "用 1% 档阈值时，检出率是多少"。

**表格里每列的意思**（以 `metrics.csv` 为准）：

| 列 | 通俗解释 |
|---|---|
| `roc_auc` | 不管阈值怎么定，分数排序得好不好（0.5=瞎排，1=完美） |
| `tpr@cf1/5/10` | 用训练分数的 99/95/90 分位当阈值时，检出率（**部署时真正能用的指标**） |
| `rfpr@1/5/10` | 同一阈值在攻击前正常段的实际误报率（**必须和 tpr 成对看**） |
| `tpr@fpr1/5` | 事后在测试集上反推阈值、卡 1%/5% 误报时的检出率（只反映排序上限，**部署时做不到**） |
| `add_s` | 首报延迟：攻击开始后，连续 3 帧报警（防抖）的第一次报警时刻 − 攻击时刻。越小越好 |
| `hit` | 是否命中（add_s 有限则 1） |

**为什么"连续 3 帧"**：单帧误报很常见（噪声尖峰），连续 3 帧都超阈值才可信——这是工程上的防抖，也是 ADD 的物理下限 0.04 秒（3 帧 × 20 ms）。

**一句话读表法**：先看 `tpr@cf1%`（能不能抓到），再看同行的 `rfpr@1%`（是不是靠虚警换来的），最后看 `add_s`（抓得快不快）。三者都好才是好方法。

## 0.5 所有方法共用的骨架

不管哪个方法，代码流程都一样：

```python
model.fit(X_train_clean)      # 只喂正常数据，学"正常长什么样"
score_test = model.score(X_test)   # 给每个测试帧打分，越大越异常
thresholds = percentile(score_train, [99, 95, 90])  # 用训练分数定三档阈值
alarm = score_test >= thresholds[0]   # 1% 档报警
```

后面每个方法的教学，都只讲一件事：**这个方法的 `score` 函数是怎么设计的**——它用什么数学公式把"正常"和"异常"分开。现在开始。

# 第一族：分布偏离法——"这一帧离正常群体有多远？"

> 族导言：这一族的方法把"正常"建模为一个**群体**（一堆历史正常样本构成一个分布），
> 然后问：新来的一帧 $\boldsymbol{z}_t$ 离这个群体有多远？离得远就报警。
> 它们的差别只在于"距离"怎么定义：欧氏、马氏、子空间内、子空间外、稳健估计。
> 阅读顺序：先学 Mahalanobis（最标准），再学它的"简化版/变形版"，最后学一个"翻车版"（MCD）——翻车本身也是课。

# 第 1 篇：Mahalanobis 距离——全科最标准的"离群尺子"

**对应结果目录**：`results/fusion/single_Mahalanobis/`　**源码**：`method_lib/traditional/Mahalanobis_MultiVar_Gaussian.py`

## 1.1 要解决的问题

想象你要在一群同学里找出"状态不对劲"的人。最简单的方法是量每个人的身高体重，看谁偏离平均值远。但问题来了：**有的维度天生波动大**（比如体重），有的维度天生波动小（比如体温）。偏离 2 公斤体重没人会注意，偏离 2 度体温就是发烧。

这就是欧氏距离的致命伤：它把所有维度一视同仁，不知道"哪些方向正常波动大、哪些方向正常波动小"。

## 1.2 核心思想（一句话）

> **先学正常群体的"波动形状"（每个方向波动多大、方向之间怎么相关），再按这个形状给每个方向的偏离"打折"。**

偏离方向若恰好是正常波动大的方向 → 打大折扣（不算异常）；偏离方向若正常几乎不波动 → 原价甚至加价（很可疑）。

## 1.3 数学怎么做

设 8 维特征向量为 $\boldsymbol{z}_t$。用训练（正常）数据估计：

$$\boldsymbol{\mu}=\frac{1}{N}\sum_{t=1}^{N}\boldsymbol{z}_t\quad(\text{正常群体的中心}),$$

$$\Sigma=\frac{1}{N-1}\sum_{t=1}^{N}(\boldsymbol{z}_t-\boldsymbol{\mu})(\boldsymbol{z}_t-\boldsymbol{\mu})^{\top}\quad(\text{8×8 协方差矩阵，记录波动形状}).$$

马氏距离就是"按 $\Sigma$ 的形状加权后的距离平方"：

$$s_t=(\boldsymbol{z}_t-\boldsymbol{\mu})^{\top}(\Sigma+\varepsilon I)^{-1}(\boldsymbol{z}_t-\boldsymbol{\mu}).$$

**每个符号的直觉**：

- $\Sigma$ 对角线 = 每个特征的方差（谁波动大）；非对角线 = 特征间相关性（比如"功率升"和"CN0 升"总是一起发生）；
- $\Sigma^{-1}$ 的作用 = 把坐标"拉直"：沿着大方差方向的偏离被压缩，沿着小方差方向的偏离被拉伸（想想：把椭球变成圆球再量距离）；
- $(\boldsymbol{z}_t-\boldsymbol{\mu})^{\top}\cdots(\boldsymbol{z}_t-\boldsymbol{\mu})$ = 拉直后的距离平方；
- $\varepsilon I$（$10^{-6}$ 小正则）= 防止 $\Sigma$ 不可逆的数值保护，数学上可忽略。

**为什么这个公式"正确"**：如果正常数据真的近似高斯分布，那么等密度面是椭球，马氏距离正是"样本偏离中心的椭球半径平方"。欺骗帧要么离中心远、要么落在正常从不出现的方向，马氏距离都会大。

## 1.4 源码怎么实现

```python
class Mahalanobis_MultiVar_Gaussian:
    def fit(self, X):
        self.mean_ = X.mean(axis=0)                       # μ：正常中心
        cov = np.cov(X, rowvar=False)                     # Σ：8×8 协方差
        self.cov_inv_ = np.linalg.pinv(cov + self.reg * np.eye(cov.shape[0]))
        return self

    def score(self, X):
        d = X - self.mean_
        return np.einsum("ni,ij,nj->n", d, self.cov_inv_, d)   # 逐帧二次型
```

逐行讲解：

1. `fit` 里只干两件事：算均值、算协方差并求逆。**"训练"其实只有这两步**——所以它毫秒级完成；
2. `pinv` 是伪逆，配合 $\varepsilon I$ 正则，即使特征几乎线性相关（比如 m_ratio 和 m_delta 高度相关）也不会除零崩溃；
3. `einsum("ni,ij,nj->n", d, cov_inv, d)` 是一个 numpy 技巧：对每帧算 $d^\top\Sigma^{-1}d$。把它展开就是 $n$ 个二次型，等价于写循环但快两个量级；
4. `score` 是无状态的：每一帧独立打分，不依赖上一帧——这是"分布偏离族"的共同特点。

## 1.5 它擅长什么、不擅长什么（实测说话）

**擅长**：

- 高功率攻击（ds1/ds2/ds5）：功率特征跳变是"大方差方向的大偏离"，打折后仍然巨大——检出率 0.998–1.000，ADD 0.04 秒（物理极限）；
- **阈值迁移最稳**：1% 档实际虚警 0.0054，几乎等于名义值 1%。因为"椭球形状"在测试通道上基本不变，阈值从训练搬到测试不会失真——这是它最大的工程优点。

**不擅长**：

- 位置推送攻击（ds3，最难场景）：攻击的漂移是**缓慢**的，每一帧只偏离一点点，单帧距离不够远——1% 档只有 0.286；
- 为什么"抓头不守尾"：拉偏开始那几百毫秒距离暴增（ADD 0.2 秒），但接管后欺骗信号自己形成了一个"稳定的新群体"，每帧距离回落——**逐帧距离法看不到"连续的小偏移在累积"**（这是第三族方法的主场）。

## 1.6 小结

马氏距离 = 把"偏离正常群体"这件事做对的标准答案：方差加权 + 去相关。它是后面所有"分布偏离法"的原点——StatThreshold 是它的"简化版"（忘了方差形状），Hotelling 是它的"子空间版"（只保留大方差方向），MCD 是它的"稳健版"（换了个估计）。学完这一篇，后面的几篇都是"改一处"。

# 第 2 篇：StatisticalThreshold——一把最简陋的尺子

**对应结果目录**：`results/fusion/single_StatThreshold/`　**源码**：`method_lib/traditional/StatisticalThreshold_SingleVar_Gaussian.py`

## 2.1 要解决的问题

如果你**没学过**马氏距离，你会怎么判断"这帧异常"？大概是这样：每个特征算一个 z 分数（偏离均值几个标准差），然后……加起来？取最大？这就是本篇的朴素做法。

## 2.2 核心思想（一句话）

> **每个特征单独算"偏离几个标准差"，然后把 8 个特征的平均偏离作为分数。**

## 2.3 数学怎么做

$$z_{f,t}=\frac{|z_{f,t}-\mu_f|}{\sigma_f},\qquad s_t=\frac{1}{8}\sum_{f=1}^{8}z_{f,t}.$$

- $\mu_f,\sigma_f$：特征 $f$ 在正常数据上的均值与标准差；
- 每个特征先标准化（变成"几个标准差"的无量纲数），再平均。

**它和马氏距离的区别**：马氏距离用 $\Sigma^{-1}$ 同时做"方差加权"和"去相关"；这里只用对角线的标准差（方差加权的一半），**完全不管特征间相关性**（去相关没了）。所以它是马氏距离的"对角线简化版"。

## 2.4 源码怎么实现

```python
def fit(self, X):
    self.mean_ = X.mean(axis=0)
    self.std_ = X.std(axis=0) + 1e-9
    return self

def score(self, X):
    s = np.abs((X - self.mean_) / self.std_)   # |z| 矩阵 [N, 8]
    return s.mean(axis=1)                       # 8 个特征平均 → 分数
```

`mean(axis=1)` 就是平均聚合发生的地方。**注意**：如果这里改成 `max(axis=1)`，就变成 StatZ 的思路（保留最强特征证据）——这个"平均 vs 最大"的分叉，后面第 12 篇还会再讲。

## 2.5 它擅长什么、不擅长什么

**擅长**：高功率攻击（ds1 0.998）——8 个特征里功率、CN0 同时大幅跳变，平均后仍然很大；虚警纪律好（1% 档实际 0.005），因为平均操作同样稀释了误报。

**不擅长**：**平均稀释**。位置推送攻击只让 2–3 个特征慢慢偏移，其余特征还在噪声范围内——平均把"2 个特征的强证据"稀释成"8 个特征的平均小证据"，1% 档只有 0.198。sophisticated（ds6）同理只有 0.306。

**教学要点**：平均聚合是"和稀泥"——它假设"异常会均匀影响所有特征"，而现实是欺骗常常**集中打击个别特征**。

## 2.6 小结

StatThreshold 是理解"聚合方式"的第一课：平均（和稀泥）vs 最大（抓最强证据）。它的存在价值是当"下界参照"——任何像样的方法都不该比它差；它和马氏距离的差距（AUC 0.940 vs 0.948，1% 档 0.697 vs 0.744）就是"方差加权+去相关"的价值。

# 第 3 篇：Hotelling T²——把数据先压扁再量距离

**对应结果目录**：`results/fusion/single_HotellingT2/`　**源码**：`method_lib/traditional/HotellingT2_MultiVar_ProcessMonitoring.py`

## 3.1 要解决的问题

8 个特征**高度相关**（功率升几乎总伴随 CN0 升；ratio 升伴随 delta 降）。相关意味着：8 维数据实际上只"占满"了更少的方向——大部分变化集中在前几个主方向（主成分）。马氏距离老老实实用全部 8 个方向，但**有些方向（小方差的）可能主要是噪声**。

Hotelling T² 的思路：先做主成分分析（PCA）把数据"压扁"到前几个主方向（保留 90% 方差），然后：

- **T² 部分**：在压扁后的子空间里量距离（看样本离正常中心多远）；
- **SPE 部分**：量"压扁时丢掉的东西"（看样本有没有子空间之外的新东西）。

## 3.2 核心思想（一句话）

> **正常的波动集中在少数主方向；异常分两种：主方向内偏离太远（T²），或出现了主方向外的成分（SPE）。两个都要看。**

## 3.3 数学怎么做

对标准化特征做主成分分解，保留累计方差 90% 的前 $k$ 个主成分（载荷矩阵 $P_k$、方差对角阵 $\Lambda$）。得分 $T_t=\boldsymbol{z}_tP_k$，重构 $\hat{\boldsymbol{z}}_t=T_tP_k^{\top}$：

$$s_t=\underbrace{\frac{T_t^{\top}\Lambda^{-1}T_t}{\max_{\text{train}}T^{\top}\Lambda^{-1}T}}_{\text{T² 项}}+\underbrace{\frac{\|\boldsymbol{z}_t-\hat{\boldsymbol{z}}_t\|_2}{\max_{\text{train}}\|\boldsymbol{z}-\hat{\boldsymbol{z}}\|_2}}_{\text{SPE 项}}.$$

- T² 项：主方向内的偏离，按主成分方差加权（大方差主方向宽容、小方差主方向严格）——和马氏距离在子空间内的版本；
- SPE 项：残差范数——样本里"正常从不出现"的成分；
- 两项各自按训练最大值归一后相加，量纲统一。

**为什么拆两项**：功率阶跃是"主方向内的强偏离"（T² 抓）；相关峰畸变可能产生"正常样本没有的组合方式"（SPE 抓）。

## 3.4 源码怎么实现

```python
def fit(self, X):
    ...
    self.pca = PCA(n_components=0.9)   # 保留累计方差 90%
    self.pca.fit(Z)
    return self

def score(self, X):
    T = self.pca.transform(Z)           # 得分 [N, k]
    rec = self.pca.inverse_transform(T) # 子空间重构 [N, 8]
    t2 = np.sum((T / (np.std(T, axis=0) + 1e-9)) ** 2, axis=1)   # 主方向内距离
    spe = np.linalg.norm(Z - rec, axis=1)                        # 主方向外残差
    return t2 / np.max(t2) + spe / np.max(spe)                   # 归一相加
```

- `PCA(0.9)` 让 sklearn 自动选 $k$（本数据特征强相关，$k\approx3$–4）；
- T² 用**测试批内**的 `std(T)` 加权（一个近似，批内方差 ≈ 训练方差，但含欺骗帧时略受污染）；
- 两项都用 `np.max` 归一——对长尾敏感，这是它虚警极其保守的原因之一。

## 3.5 它擅长什么、不擅长什么

**擅长**：虚警纪律**全场最佳**（1% 档实际虚警 0.0004，比名义 1% 还低）——max 归一 + 双统计量天然保守；时间调整类攻击（ds7/ds8，1% 档 0.56）反而可用，因为时间篡改会缓慢改变特征组合关系、逐渐漏进残差。

**不擅长（重要！）**：匹配功率与 sophisticated 场景**几乎失明**（ds2 1% 档 0.006、ds6 0.036）。为什么？**PCA 把大方差方向当作"正常方向"宽容处理，而欺骗恰好利用这些方向**——匹配功率攻击主打的畸变特征方差大、被 PCA 收进子空间内并被宽容加权；sophisticated 的攻击组合"太像正常"，T² 和 SPE 都没信号。这是子空间法的结构性盲区。

## 3.6 小结

Hotelling T² = "压扁后量距离（T²）+ 量压扁丢掉的（SPE）"。它是理解"为什么不能随便截断维度"的绝佳案例：**在 8 维小特征集上，截断子空间损失的信息大于抗噪收益**（对比马氏全协方差 0.948 vs 本方法 0.827）。

# 第 4 篇：PCA 重构残差——只看"压扁后剩多少"

**对应结果目录**：`results/fusion/single_PcaReconstruction/`　**源码**：`method_lib/traditional/PcaReconstruction_MultiVar_Correlated.py`

## 4.1 要解决的问题

上一篇的 Hotelling 用两个量（T²+SPE）。这一篇问：**只保留 SPE 一个量，够不够？**——它是严格的"单变量消融实验"：和 Hotelling 用同一个 PCA，只是 score 里删掉 T² 项。

## 4.2 核心思想（一句话）

> **正常数据的信息集中在少数主方向；如果一帧有"主方向之外"的能量，它就不正常。**

## 4.3 数学怎么做

$$s_t=\|\boldsymbol{z}_t-P_kP_k^{\top}\boldsymbol{z}_t\|_2,$$

即"投影到主方向再投影回来"的误差范数。$P_kP_k^{\top}\boldsymbol{z}$ 是 $\boldsymbol{z}$ 在子空间内的最佳近似，误差就是"子空间外成分"。

## 4.4 源码怎么实现

```python
def fit(self, X):
    ... self.pca = PCA(n_components=0.9); self.pca.fit(Z) ...
def score(self, X):
    T = self.pca.transform(Z)
    rec = self.pca.inverse_transform(T)
    return np.linalg.norm(Z - rec, axis=1)    # 只留 SPE，删掉 T²
```

和 Hotelling 的**唯一区别**就是 `score` 少了一行（删掉 t2 项）。这就是消融实验的教学范本：两方法同 PCA、同数据，差异可完全归因于"有没有 T² 项"。

## 4.5 它擅长什么、不擅长什么

**不擅长到离谱**：三个场景 AUC **低于 0.5（反向）**——欺骗帧的重构误差反而比正常帧小！

**为什么反向**：欺骗接管后跟踪环路锁得很好，特征组合"非常干净"，几乎全落在主方向内（残差小）；而正常动态段（cd）的运动噪声让残差很大。于是"残差大"变成"像正常运动"的信号，"残差小"反而像异常——**排序完全倒挂**。

这个结果极有教学价值：**SPE 单独使用时，把"欺骗=更干净"当成了"欺骗=异常"**。它证明了 Hotelling 里 T² 项是不可或缺的（AUC 0.601 vs 0.827）。

## 4.6 小结

PCA 重构残差是"只留 SPE"的反面教材：在 SQM 特征上，欺骗样本在子空间内比正常更"规整"，残差方向携带的几乎全是运动噪声。它教我们：**不要轻易丢弃一半的统计量，除非你验证过它携带的是信号而不是噪声**。

# 第 5 篇：Mahalanobis-MCD——换一把"更抗脏"的尺子（反面教材）

**对应结果目录**：`results/fusion/single_MahalanobisMCD/`　**源码**：`run_extras_v31.py` 内 `class MahalanobisMCD`

## 5.1 要解决的问题（动机是好的）

马氏距离用全体正常数据的均值/协方差。但"正常数据"里其实混着"脏正常"——多径、周跳恢复期等异常但非欺骗的帧。这些脏样本会把协方差"吹胀"，椭球变大、阈值变松、检出变差。

**MCD（最小协方差行列式）**是稳健统计里的经典解法：只挑"最紧凑的一半"样本估计均值和协方差，理论上能容忍训练集里最多 25% 的脏样本。

## 5.2 核心思想（一句话）

> **不用全部正常数据估计形状，只用"最像正常的那一半"。**

## 5.3 数学怎么做

$$(\hat{\boldsymbol{\mu}}_{\text{MCD}},\hat{\Sigma}_{\text{MCD}})=\arg\min_{|H|=h}\ \det\big(\operatorname{Cov}(X_H)\big),\qquad h=\lceil(n+p+1)/2\rceil,$$

即：在所有大小为 $h$（约一半）的子集中，找协方差行列式最小的那个（"最紧凑"的子集）。然后距离公式和马氏完全一样，只是参数换成 MCD 估计：

$$s_t=(\boldsymbol{z}_t-\hat{\boldsymbol{\mu}}_{\text{MCD}})^{\top}(\hat{\Sigma}_{\text{MCD}}+\varepsilon I)^{-1}(\boldsymbol{z}_t-\hat{\boldsymbol{\mu}}_{\text{MCD}}).$$

## 5.4 源码怎么实现

```python
class MahalanobisMCD:
    def fit(self, X):
        mcd = MinCovDet(random_state=2, support_fraction=None).fit(X)  # 50% 支撑
        self.mean_ = mcd.location_
        self.cov_inv_ = np.linalg.pinv(mcd.covariance_ + 1e-6 * np.eye(X.shape[1]))
        return self
    def score(self, X):
        d = np.asarray(X) - self.mean_
        return np.einsum("ni,ij,nj->n", d, self.cov_inv_, d)
```

和普通马氏的代码几乎一样——**唯一区别是 fit 里的估计方法**。这正是它作为"单变量对照"的价值。

## 5.5 它为什么翻车了（重点教学）

宏平均 1% 档只有 **0.081**（普通马氏 0.744），AUC 0.759。翻车原因有两层：

1. **深层：选错"哪一半"**。训练集是 cs 静态簇 + cd 动态簇，各占一半。50% 支撑的子集可能**整体丢掉其中一簇**（比如只保留 cs）——它估计的不是"核心正常分布"，而是"半个世界"。动态测试帧（ds4/ds5）因此整体变成"离群"，分数分布错位。
2. **表层：标定口径错配**。阈值仍然按**全部训练集**分数的 p99/p95/p90 标定，而被 MCD 丢弃的那一半（分数极高）把 p99 推得老高——测试帧几乎无法越限。

**教学结论**：单类检测里，**估计器与阈值标定必须共享同一个"什么是正常"的定义**。你换了更稳健的估计器，却还按旧口径标定阈值，等于"用了新尺子、旧刻度"。

## 5.6 小结

MCD 的教训是方法论级的：更复杂的估计**不会自动**带来更好的检测器——它只是换了一种"什么是正常"的定义，而阈值标定必须跟着换。这也是为什么后面所有方法都强调"阈值=训练分数分位"这一口径的一致性。

# 第 6 篇：kNN 距离——"离最近的正常人多远"

**对应结果目录**：`results/fusion/single_KnnDist/`　**源码**：`run_fusion_v31.py` 内 `class KnnDist`

## 6.1 要解决的问题

马氏距离假设正常数据是"一个椭球"。但如果正常数据其实是**两个团**（cs 静态团 + cd 动态团）或者弯弯曲曲的形状呢？一个椭球装不下两个团——参数假设开始漏水。

**非参数解法**：我不假设任何形状，直接把全部正常样本存着，来一个新样本就量它"离最近的几个正常样本多远"。

## 6.2 核心思想（一句话）

> **把 45476 个正常样本当参照库：新样本到最近 $k$ 个参照的平均距离就是异常分数。远 = 落在地图的空白区 = 可疑。**

## 6.3 数学怎么做

$$s_t=\frac{1}{k}\sum_{i=1}^{k}\big\|\boldsymbol{z}_t-\boldsymbol{z}_{(i)}\big\|_2,\qquad k=5,$$

其中 $\boldsymbol{z}_{(1)},\dots,\boldsymbol{z}_{(k)}$ 是参照库里离 $\boldsymbol{z}_t$ 最近的 $k$ 个样本。$k=5$ 的作用是平滑：单个最近邻可能被噪声抖动，5 个平均更稳。

**直觉联系**：距离大 ⇔ 样本落在正常样本稀疏区 ⇔ 密度低。粗略地，$\hat p(\boldsymbol{z})\propto 1/r_k^d$（第 $k$ 近邻距离的倒数近似局部密度），所以 kNN 距离本质是一个**非参数密度估计的倒数**。

## 6.4 源码怎么实现

```python
class KnnDist:
    def __init__(self, k=5): self.k = k

    def fit(self, X):
        self.nn = NearestNeighbors(n_neighbors=self.k, n_jobs=-1).fit(X)  # 建索引
        return self

    def score(self, X):
        out = np.empty(len(X))
        for i in range(0, len(X), 20000):                 # 分块防内存
            out[i:i+20000] = self.nn.kneighbors(X[i:i+20000])[0].mean(axis=1)
        return out
```

- `fit` 只建近邻索引（sklearn 自动选 KD 树或暴力搜索）——"训练"其实是零学习，所以叫**惰性学习器**；
- `kneighbors` 返回 `[块大小, k]` 的距离矩阵，`mean(axis=1)` 就是 $s_t$；
- 分块 20000 是工程折衷：一次算 20000×45476 的距离矩阵不至于爆内存；
- 推理成本：单帧查询微秒级，50 Hz 实时毫无压力（45476 样本、8 维很小）。

## 6.5 它擅长什么、不擅长什么

**擅长**：

- **检出是全部"库版方法"里最高的**（1% 档宏平均 0.834，超过马氏 0.744、OCSVM 0.810）：非参数表达多簇/弯曲形状的能力兑现；
- 匹配功率（ds2 1.000）与 sophisticated（ds6 0.785）都强——正常流形之外的样本，距离法天然敏感。

**不擅长（交学费的地方）**：**虚警税**。1% 档实际虚警 0.040（名义的 4 倍），且集中在动态场景（ds5/ds6 的 0.115/0.117）。为什么？参照库里 cs 静态团样本多、cd 动态团样本少——**团密度不均**，落在 cd 团边缘的测试帧"离正常人的平均距离"天然偏大，即使它本身是正常动态帧。这是非参数法的固有税：**你的分数依赖"参照库采样得多密"，而不只是"样本有多异常"**。

## 6.6 小结

kNN 距离是"非参数化"的第一课：灵活（任何形状都行）、检出高，但**分数携带了参照库密度信息**，跨场景部署时虚警会漂移。它是理解 LOF（想修密度不均）的起点。

# 第 7 篇：LOF——"周围密度跟我比差多少"

**对应结果目录**：`results/fusion/single_LOF/`　**源码**：`method_lib/traditional/Lof_MultiVar_LocalDensity.py`

## 7.1 要解决的问题

kNN 距离有个不舒服的地方：**密度不均时分数失真**（见上篇）。LOF 想修这个：不看"绝对距离"，看"**相对密度**"——我周围的密度，和我的邻居周围的密度，差多少？

## 7.2 核心思想（一句话）

> **如果我的邻居都住得很挤（密度高），而我这里很空旷（密度低），那我很可能是误入歧途的离群点。**

## 7.3 数学怎么做

先定义"局部可达密度"（邻居们到我这里平均要多远，取倒数）：

$$\operatorname{lrd}(p)=\left(\frac{1}{|N_k(p)|}\sum_{q\in N_k(p)}\operatorname{reach}_k(p,q)\right)^{-1},$$

其中 $\operatorname{reach}_k(p,q)=\max\{d_k(q),\,d(p,q)\}$（可达距离，防止分母过小）。LOF 分数是密度比：

$$s_t=\mathrm{LOF}(p)=\frac{1}{|N_k(p)|}\sum_{q\in N_k(p)}\frac{\operatorname{lrd}(q)}{\operatorname{lrd}(p)},\qquad k=20.$$

- $\mathrm{LOF}\approx1$：我密度和邻居差不多 → 正常；
- $\mathrm{LOF}\gg1$：我明显比邻居稀疏 → 离群。

**为什么除以邻居密度能修密度不均**：不管你是住在密区还是疏区，只要你和邻居同密度，LOF≈1——它把"绝对密度"归一掉了。

## 7.4 源码怎么实现

```python
def fit(self, X):
    ... self.clf = LocalOutlierFactor(n_neighbors=20, contamination=0.01, novelty=True)
    self.clf.fit(Z); return self

def score(self, X):
    return -self.clf.decision_function(Z)   # decision_function 越大越正常 → 取负
```

- `novelty=True` 是关键：允许对训练集**之外**的新样本打分（否则只能对训练集内部互评，没法做测试）；
- `contamination=0.01` 只影响内部二值预测的偏移，不影响连续分数——阈值仍由我们的清洁分位决定；
- $k=20$ 比 kNN 的 $k=5$ 大：密度估计需要更多邻居才稳。

## 7.5 它擅长什么、不擅长什么

**擅长**：排序能力好（AUC 0.928），六个场景 ≥0.92；ds6（sophisticated）表观检出 0.868。

**不擅长（两笔学费）**：

1. **"集群式异常"盲区**：欺骗帧不是零星几帧，而是**连成一大片**（一个场景 1.5 万帧互相为邻）。它们自己形成密集簇，LOF≈1，直接漏检——LOF 设计给"点状离群"，而欺骗是"集群异常"；
2. **阈值迁移税全场最重**：1% 档实际虚警 0.110（名义的 11 倍）！密度比同时受"参照库密度"和"我的密度"影响，分子分母一起漂移，分数整体平移。**表观 0.868 的检出，是在实际虚警 16.5% 的档位上换来的**——这就是"名义 FPR 有误导性"的最佳教材。

## 7.6 小结

LOF 想用"相对密度"修 kNN 的密度不均，但引入了两个新问题：集群异常漏检 + 更大的阈值迁移。它教会我们：**"更聪明"的归一不一定更稳——当你归一掉密度时，可能把信号也归一掉了**。

# 第 8 篇：OCSVM——用一个气球包住正常数据

**对应结果目录**：`results/fusion/single_OCSVM/`　**源码**：`run_fusion_v31.py` 内 `class Ocsvm`

## 8.1 要解决的问题

马氏距离的椭球太"圆"（只能一个中心），kNN/LOF 又太"散"（逐点判断）。能不能有一种方法：**画一个任意形状的气球，把正常数据全部包在里面，气球表面就是决策边界**？

## 8.2 核心思想（一句话）

> **在核空间里找一个超平面，把正常数据和原点分开——气球的"边界"由边界附近的正常样本（支持向量）决定。**

## 8.3 数学怎么做

$$s_t=\rho-\sum_{i\in SV}\alpha_i K(\boldsymbol{z}_i,\boldsymbol{z}_t)\qquad(\text{越大越异常}),$$

$K$ 是 RBF 核 $K(\boldsymbol{z},\boldsymbol{z}')=\exp(-\gamma\|\boldsymbol{z}-\boldsymbol{z}'\|^2)$，$(\alpha_i,\rho)$ 由求解下面这个"最大间隔"问题得到：

$$\min_{\boldsymbol{w},\rho,\xi}\ \frac{1}{2}\|\boldsymbol{w}\|^2+\frac{1}{\nu n}\sum_i\xi_i-\rho,\quad \text{s.t.}\ \boldsymbol{w}^{\top}\phi(\boldsymbol{z}_i)\ge\rho-\xi_i.$$

**参数直觉**：

- $\nu=0.02$：大约 2% 的训练帧可以落在边界外——它同时约束"训练误差上限"和"支持向量数量下限"，可以理解为"边界多紧"；
- $\gamma=\text{scale}$：核宽度（$\approx1/8$，因为已标准化）。$\gamma$ 大 → 气球贴每个样本（过拟合噪声）；$\gamma$ 小 → 气球太松。**$\gamma$ 是这个方法唯一敏感的参数**（网格实验：$\gamma=0.5$ 时判决饱和，实际虚警 35%，完全不可用）。

**几何直觉**：RBF 核下，这个方法等价于"在每个支持向量周围放一个小高斯，高斯叠起来的外轮廓就是边界"——边界可以任意弯曲，比椭球灵活得多。

## 8.4 源码怎么实现

```python
class Ocsvm:
    def fit(self, X):
        self.clf = OneClassSVM(kernel="rbf", nu=0.02, gamma="scale").fit(X)
        return self
    def score(self, X):
        return -self.clf.score_samples(X)   # 到边界的带符号距离，取负
```

- 训练复杂度 $O(n^2\sim n^3)$，45476 样本约 1–3 分钟（一次性成本）；
- 推理只和**支持向量**（约 $\nu n\approx900$ 个）求核——很快；
- `score_samples` 是"到边界的符号距离"，负值 = 边界外 = 异常侧。

## 8.5 它擅长什么、不擅长什么

**擅长**：**ds6（sophisticated）是它的招牌场景**——1% 档 0.824@实际虚警 0.066，全方法第一梯队。为什么？RBF 边界对"域外稀疏样本"特别敏感：拉偏瞬态和接管后的残余偏移都让样本落到边界外的稀疏区，核相似度骤降。气球的"局部自适应"在弱签名场景兑现。

**不擅长**：位置推送（ds3 0.352@1%）——微漂移让样本贴着边界滑，核相似度只微降；阈值迁移中等（1% 档实际虚警 0.023，好于 LOF 差于马氏）。

## 8.6 小结

OCSVM = "用核函数画一个可弯曲的气球"。它展示了从"参数化"到"核化"的跃迁：边界形状由数据决定而非假设决定。代价是 $\gamma$ 敏感、训练较慢——这是"灵活性"的账单。

# 第 9 篇：Isolation Forest——把离群点快点切出来

**对应结果目录**：`results/fusion/single_IF/`　**源码**：`method_lib/traditional/IsolationForest_MultiVar_NonGaussian.py`

## 9.1 要解决的问题

前面所有方法都在回答"这个样本离正常群体多远"。IF 换了一个完全不同的问法：

> **如果我把数据反复随机切两半，这个样本需要切几次才能被单独切出来？**

## 9.2 核心思想（一句话）

> **离群点"少而不同"，随机切分几下就把它孤立了；正常点深埋在密集区，要切很多刀。**

## 9.3 数学怎么做

每棵树：随机选一个特征、随机选一个切分值，递归二分，直到叶子单点。样本的"孤立难度"用平均路径长度 $E[h(\boldsymbol{z})]$ 衡量，归一化后：

$$s_t=-\,2^{-E[h(\boldsymbol{z}_t)]/c(n)},$$

$c(n)=2H(n-1)-\frac{2(n-1)}{n}$ 是二叉搜索树的平均路径长度（归一化常数）。$s\to1$：切几刀就孤立（强异常）；$s\to0$：深埋分布内部（正常）。

**直觉类比**：你在玩"猜数字"游戏，随机提问逐步缩小范围。一个明显离群的数（比如 9999）很快就被问出来了；一个正常的数要问很多轮。

## 9.4 源码怎么实现

```python
def fit(self, X):
    self.clf = IsolationForest(n_estimators=200, contamination=0.01, random_state=0, n_jobs=-1)
    self.clf.fit(X); return self

def score(self, X):
    return -self.clf.score_samples(X)   # score_samples 越大越正常 → 取负
```

- 200 棵树、每棵树随机子采样 256 个样本（`max_samples="auto"`）——子采样让训练 O(n) 且抗过拟合；
- `contamination=0.01` 同样只影响二值预测，不影响连续分数；
- 推理 = 每棵树走一条根到叶的路径取平均——**全部方法中推理最快**（单帧微秒级）。

## 9.5 它擅长什么、不擅长什么

**擅长**：速度（训练 4 秒、测试 176k 帧 2 秒，比 OCSVM 快两个数量级）；虚警纪律好（1% 档实际 0.005）。

**不擅长（两个结构性弱点）**：

1. **档间跳变**：分数来自路径长度的离散化，呈"台阶"状。1% 档只有 0.310，5% 档跳到 0.546——阈值微移，检出跳变。随机切分的颗粒度限制了分数分辨率；
2. **集群式异常 + 稳态欺骗都失明**：欺骗帧 1.5 万帧互相为伴，随机切分会给它们建出自己的叶子区，孤立难度不高；接管后"安稳落座"的欺骗帧更是深埋。ds6 三档 ≤0.47。

**教学要点**：IF 是"孤立范式 vs 距离/密度范式"的分水岭——它不计算任何距离或密度，因此对"整体搬家"（所有样本一起漂移）完全无感。

## 9.6 小结

IF 教我们第三类异常观：**离群 = 容易孤立**。它极快、虚警纪律好，但分数分辨率差、集群异常失明。适合当"粗筛"（高召回低精度预筛），不适合当最终判决。

# 第二族小结（三张牌的对比）

| 方法 | 问的问题 | 优势 | 代价 |
|---|---|---|---|
| kNN | 离最近的正常人多远？ | 检出最高（0.834）、任何形状 | 参照库密度不均 → 虚警税 0.040 |
| LOF | 周围密度比我差多少？ | 相对密度、理论更公平 | 集群异常漏检、迁移税 0.110 |
| OCSVM | 在核气球边界内吗？ | 边界可弯曲、ds6 招牌 | γ 敏感、训练慢 |
| IF | 切几刀能孤立？ | 最快、虚警纪律好 | 分数台阶化、集群失明 |

**共性教训**：非参数法都背着"参照库密度"的包袱——分数不仅反映样本有多异常，还反映"参照库在这里采样得多密"。这为第三族的"时间累积法"铺路：它们不依赖参照库密度，而是依赖"时间上的持续性"。

# 第三族：时间累积法——"这不是噪声，是持续的偏移"

> 族导言：前两族都是**逐帧独立**判断（每帧单独打分，忘了过去）。但欺骗的一个本质特征是**持续性**：
> 位置推送的漂移每帧只有一点点（淹没在噪声里），可它**一直在往同一个方向偏**。
> 逐帧方法看不到"持续的微小偏移"，因为单帧的信噪比不够。
> 第三族的方法利用**时间结构**：把过去的信息累积/加权起来，让"持续的小偏移"变成"累积的大信号"。
> 教学主线：EWMA（指数加权平均）→ CUSUM（无界累积）→ StatZ（单帧检验的教训）→ 改进①MEWMA → 改进②MCUSUM。

# 第 10 篇：EWMA——"最近 5 帧的平均水平"

**对应结果目录**：`results/fusion/single_EWMA/`　**源码**：`method_lib/traditional/Ewma_SingleVar_Online.py`

## 10.1 要解决的问题

逐帧阈值有个尴尬：单帧噪声很大，一个正常的抖动也可能让某一帧分数超阈值（误报）；而真实的持续偏移，单帧又不够明显（漏检）。**能不能给"历史"一点权重，让分数更稳？**

## 10.2 核心思想（一句话）

> **每帧的新分数 = 新观测 × λ + 上一帧分数 × (1−λ)。等价于"指数加权的移动平均"：最近的帧权重最大，越远的帧越被遗忘。**

## 10.3 数学怎么做

对每个特征维护指数加权状态：

$$E_{f,t}=\lambda\, z_{f,t}+(1-\lambda)\,E_{f,t-1},\qquad \lambda=0.2,$$

检测统计量取各特征 EWMA 绝对值的平均：

$$s_t=\frac{1}{8}\sum_{f=1}^{8}\big|E_{f,t}\big|.$$

**为什么要指数加权而不是简单平均**：简单平均对窗口内所有帧一视同仁（突变被瞬间稀释）；指数加权让"最近的"最有发言权——对阶跃响应快，又比单帧稳。**等效记忆窗约 $1/\lambda=5$ 帧（100 ms）**，方差缩到 $\lambda/(2-\lambda)\approx0.11$ 倍——噪声被压掉约 3 倍，信噪比提升。

**直觉类比**：你判断"今天天气趋势"时，主要看最近几天，而不是把过去一个月平均——EWMA 就是这个"越来越淡忘"的加权。

## 10.4 源码怎么实现

```python
def fit(self, X):
    self.mean_ = X.mean(axis=0); self.std_ = X.std(axis=0) + 1e-9
    return self

def score(self, X):
    z = (X - self.mean_) / self.std_
    ewma = np.zeros_like(z)
    acc = np.zeros(z.shape[1])
    for i in range(z.shape[0]):                       # 逐帧递推
        acc = self.lam * z[i] + (1 - self.lam) * acc  # E_t = λz_t + (1-λ)E_{t-1}
        ewma[i] = acc
    return np.abs(ewma).mean(axis=1)                  # |E| 跨特征平均
```

**两个关键教学点**：

1. `acc` 是状态变量，从 0 开始**逐帧递推**——所以它是**有状态**的方法，必须**分块调用**（驱动层：训练按 cs/cd 块、测试按场景块，每块从零开始），否则状态会跨场景"携带"，把上一个场景的余温带进下一个场景；
2. `np.abs(ewma).mean(axis=1)` 是**库版的聚合方式**：先取绝对值再平均。**这个写法丢了两样东西**——偏移的**方向**（正负偏移互相抵消在平均里）和特征间的**相关性**（相关特征被重复计分）。这正是后面 MEWMA（改进①）改的地方。

## 10.5 它擅长什么、不擅长什么

**擅长（改造前最强单方法！）**：

- 宏平均：AUC 0.9845、1% 档 **0.875**@实际虚警 0.0089、5% 档 0.965、ADD 8/8 亚秒；
- 高功率（ds1 0.998）、匹配功率（ds2 1.000）、动态（ds4/ds5 0.979–0.999）、**sophisticated（ds6 0.953@0.036）**——水平漂移类攻击全是它的主场；ds6 已持平 Paper A 的 94.7%@1.37%。

**不擅长**：位置推送（ds3 1% 档 0.399）——慢漂移每帧偏移 < 噪声，5 帧的记忆**来不及累积**就被新噪声冲淡（累积深度不够）。这是"记忆有限"方法的固有天花板。

## 10.6 小结

EWMA = "指数遗忘的移动平均"。它教会两件事：**时间滤波能同时降噪（虚警）和放大持续偏移（检出）**；但**记忆长度决定它能抓到多慢的漂移**。下一站 CUSUM 把记忆改成"无界"。

# 第 11 篇：CUSUM——把每次的小偏移攒起来

**对应结果目录**：`results/fusion/single_CUSUM/`　**源码**：`method_lib/traditional/Cusum_SingleVar_Online.py`

## 11.1 要解决的问题

EWMA 的 5 帧记忆是"双刃剑"：太快忘记 → 抓不到慢漂移。能不能**永不忘记**，把每一次的小偏移都攒起来？代价是"噪声也会被攒起来"——所以需要聪明的攒法。

## 11.2 核心思想（一句话）

> **只累积"超过容许带 $k$ 的那部分偏移"，一旦往反方向偏就清零重来。这样：持续的同向偏移被指数放大，随机噪声永远攒不起来。**

## 11.3 数学怎么做

对通道均值 $\bar z_t=\frac{1}{8}\sum_f z_{f,t}$ 维护两个累积量（上偏、下偏）：

$$C^{+}_t=\max\!\big(0,\ C^{+}_{t-1}+\bar z_t-k\big),\qquad
C^{-}_t=\max\!\big(0,\ C^{-}_{t-1}-\bar z_t-k\big),$$

$$s_t=\frac{\max(C^{+}_t,\,C^{-}_t)}{h},\qquad k=0.5,\ h=5.$$

**每个符号的直觉**：

- $k=0.5$（容许带）：每帧先扣掉 0.5 再累积——小于 0.5 的偏移当噪声忽略，只有"持续超过 0.5"的偏移才积累；
- $\max(0,\cdot)$（重置）：一旦往反方向偏，累积清零重来——**这是虚警免疫的关键**：随机噪声正负交替，永远攒不满；
- $h=5$（决策门限）：累积量除以 5 就是分数，超过 1 即"越限"。

**信噪比增长的证明直觉**：幅度 $\delta$ 的持续漂移，累积量以每帧 $(\delta-k)$ 增长；$n$ 帧后信号 $\approx n(\delta-k)$，而噪声只按 $\sqrt{n}$ 增长——**信噪比按 $\sqrt{n}$ 增长**，这就是"任意慢的漂移最终都能被检测"的数学根源。**CUSUM 是序贯变化检测的经典最优检验**（对已知幅度漂移，检测延迟有理论下界）。

## 11.4 源码怎么实现

```python
def fit(self, X):
    self.mean_ = X.mean(axis=0); self.std_ = X.std(axis=0) + 1e-9
    return self

def score(self, X):
    z = (X - self.mean_) / self.std_
    s_plus = np.zeros(z.shape[0] + 1); s_minus = np.zeros(z.shape[0] + 1)
    for i in range(z.shape[0]):
        s_plus[i+1]  = max(0.0, s_plus[i]  + z[i].mean() - self.k)   # ← 先均值
        s_minus[i+1] = max(0.0, s_minus[i] - z[i].mean() - self.k)
    return np.maximum(s_plus[1:], s_minus[1:]) / self.h
```

**关键教学点（这是整个项目的伏笔）**：`z[i].mean()` —— **先对 8 维取均值，再累积**。欺骗导致的各特征偏移**方向相反**（功率/CN0 上升、ratio/delta 下降），均值直接互相抵消！位置推送的漂移集中在 2–3 个特征上，平均后被稀释 8 倍，累积速度贴着容许带 $k$ 慢慢爬——所以库版 CUSUM 在 ds3 只有 0.284、ADD 25.74 秒。**这个"先均值后累积"的写法，正是第 14 篇改进②（MCUSUM）要推翻的。**

## 11.5 它擅长什么、不擅长什么

**擅长**：**虚警纪律全场唯一满分**——1% 档实际虚警逐场景全 0.0000（约 4.4 万清洁帧零误报）！max(0,·) 重置机制对短时波动的免疫在真实数据上完全兑现。

**不擅长**：检出被均值聚合拖累（宏 0.744），ds3 0.284、ds6 0.583。

## 11.6 小结

CUSUM 教我们：**"永不忘记的累积 + 防噪声的重置"是检测持续漂移的最优武器**，但"聚合方式"（先均值）会亲手毁掉它——把异号偏移互相抵消。这个矛盾，就是改进② MCUSUM 的诞生地。

# 第 12 篇：StatZ 与 StatZ-CN0——单帧检验的两堂课（都是教训）

**对应结果目录**：`results/fusion/single_StatZ/`、`results/fusion/single_StatZCN0/`　**源码**：`run_extras_v31.py` 内 `class StatZ` / `class StatZCN0`

## 12.1 要解决的问题

如果你"不会"时间累积，纯逐帧怎么做？最简单的单帧检验：每个特征算"偏离正常中位数几个 MAD"，取最强的那个特征。这一篇两个方法都**故意失败**了，失败比成功更值得学。

## 12.2 StatZ：稳健 max-z

$$s_t=\max_{f}\ \frac{|x_{f,t}-\mathrm{med}_f|}{1.4826\cdot\mathrm{MAD}_f},$$

中位数/MAD（乘 1.4826 与标准差对齐）比均值/标准差抗脏（50% 崩溃点），max 取"最强单特征证据"。

**为什么失败（第一课：尺度饱和）**：dB 域的 received_power 分布有界重尾——大部分样本贴着一侧边界，MAD 极小，z 分数在尾部"饱和"（p99 ≈ p99.9，分数封顶）。结果：训练分数的 p99 与 p99.9 几乎重合，**分位阈值失去分辨力**，测试帧无论怎么打分都够不到阈值。宏平均 1% 档只有 0.008、**8 个场景 ADD 全部未命中**。

**教学结论**：**分位数阈值标定隐含"分数分布连续且不饱和"的前提**。统计量设计完，第一件事就是检查训练分数的分位谱（p50/p90/p99/p99.9 间隔）——间隔坍缩 = 方法不可用。

## 12.3 StatZ-CN0：条件化统计基线

SQM 指标的噪声方差随载噪比变化（物理上 $\mathrm{Var}\propto 1/(C/N_0\cdot T)$），所以把 med/MAD 按 CN0 以 2 dB 分档分别估计：

$$s_t=\max_{f}\ \frac{|x_{f,t}-\mathrm{med}_f(\mathrm{CN0}_t)|}{1.4826\cdot\mathrm{MAD}_f(\mathrm{CN0}_t)}.$$

**为什么也失败（第二课：条件变量被攻击污染）**：位置推送攻击的漂移与 CN0 变化**伴生**（拖偏过程 CN0 轻微下降）——按 CN0 条件化等于"把与攻击伴随的 CN0 变化当作正常条件扣除"，**亲手删掉了一部分攻击证据**。证据：ds3 的 AUC 只有 0.447（**低于 0.5，反向**！）。

**教学结论**：**条件变量必须外生于攻击**（如接收机自知的运动状态），不能用攻击能直接扰动的信号质量指标当条件。

## 12.4 小结

这两堂课是"方法可用性预检"的教材：**统计量设计 → 检查分数分位谱（防饱和）→ 检查条件变量是否外生（防污染）**。两个失败方法在论文里作为"负面结果"，比正面结果更能说明方法论。

# 第 13 篇：MEWMA——改进①：给 EWMA 装上"方向感"

**对应结果目录**：`results/fusion/single_MEWMA/`　**源码**：`run_fusion_v31.py` 内 `class MEWMA`
**文献依据**：Lowry, Woodall, Champ & Rigdon (1992), *Technometrics* 34:46–53（多元 EWMA 的开山之作）

## 13.1 要解决的问题

库版 EWMA 的 `|E| 平均` 有两个数学缺陷（第 10 篇埋的伏笔）：

1. **丢了方向**：对称畸变中 ratio 升、delta 降，绝对值平均后方向信息消失——"往哪个方向偏"其实是判别信息；
2. **忽略相关性**：SQM 特征强相关（ratio≈−delta），独立求和等于把同一份证据重复计分，虚警方差被高估。

## 13.2 核心思想（一句话）

> **把 8 维 EWMA 状态当向量保留，用"协方差椭球上的距离"（二次型）当分数——方向与相关性都保留。**

## 13.3 数学怎么做

$$\boldsymbol{E}_t=\lambda\boldsymbol{z}_t+(1-\lambda)\boldsymbol{E}_{t-1},\qquad
s_t=\boldsymbol{E}_t^{\top}\Sigma_E^{-1}\boldsymbol{E}_t,\qquad
\Sigma_E=\frac{\lambda}{2-\lambda}\,\Sigma_z,$$

$\Sigma_z$ 是清洁特征的 8×8 协方差（加正则求逆），$\Sigma_E$ 是 EWMA 状态的稳态协方差（Lowry 1992 的标准结果）。

**与马氏距离的关系**：$s_t$ 就是"马氏距离作用在 EWMA 状态上"——状态 $\boldsymbol{E}_t$ 替代原始帧，协方差椭球替代欧氏度量。它同时拿到了 EWMA 的降噪（时间维度）和马氏的加权（空间维度）。

## 13.4 源码怎么实现

```python
class MEWMA:
    def __init__(self, lam=0.2, reg=1e-6): ...
    def _run(self, Z):
        E = np.zeros(Z.shape[1])
        q = np.empty(len(Z))
        for i in range(len(Z)):
            E = self.lam * Z[i] + (1 - self.lam) * E     # 向量 EWMA（和库版一样）
            q[i] = float(E @ self.Sigma_inv @ E)          # ← 唯一改动：二次型
        return q
    def fit(self, Z):
        cov = np.cov(Z, rowvar=False) * self.lam / (2 - self.lam)
        self.Sigma_inv = np.linalg.pinv(cov + self.reg * np.eye(Z.shape[1]))
        return self
```

**与库版 EWMA 的代码差异只有一行**：统计量从 `np.abs(ewma).mean(axis=1)` 换成 `E @ Σ⁻¹ @ E`。这就是"受控消融"——改进效果可完全归因于这一行。

## 13.5 改进的效果（实测）

- **虚警纪律显著改善**：1% 档实际虚警 0.0089 → **0.0051**（−43%），5%/10% 档同样全面下降——协方差加权消除了相关特征重复计分；
- **检出略降**：1% 档 0.875 → 0.831——二次型对"沿清洁相关方向爬行"的慢漂移（ds3/ds6）不如绝对值平均敏感：椭球在相关方向被拉长、被降权。**方向信息是双刃剑**；
- **与库版形成方向互补**：库版强在 ds3/ds6（相关方向漂移），MEWMA 强在虚警纪律与静态场景同检出零虚警。

## 13.6 小结

MEWMA 是"改进方法论"的样板：**找出现有方法的数学缺陷 → 用文献中的成熟工具（Lowry 1992）修掉 → 用单变量消融验证效果 → 诚实报告代价**（虚警降但相关方向检出也降）。它给融合提供了"纪律好"的通道。

# 第 14 篇：MCUSUM——改进②：给 CUSUM 拆成 8 条跑道

**对应结果目录**：`results/fusion/single_MCUSUM/`　**源码**：`run_fusion_v31.py` 内 `class MCUSUM`
**文献依据**：Woodall & Ncube (1990) 多元 CUSUM 思路

## 14.1 要解决的问题

库版 CUSUM 的致命伤（第 11 篇的伏笔）：`z[i].mean()` **先均值后累积**——异号偏移互相抵消、稀疏漂移被稀释 8 倍。ds3 只有 0.284。

## 14.2 核心思想（一句话）

> **不均值了！8 个特征各跑各的 CUSUM（8 条跑道），取最强那条当分数。方向抵消和稀释问题一起消失。**

## 14.3 数学怎么做

$$C^{+}_{f,t}=\max\!\big(0,\ C^{+}_{f,t-1}+z_{f,t}-k\big),\qquad
C^{-}_{f,t}=\max\!\big(0,\ C^{-}_{f,t-1}-z_{f,t}-k\big),\qquad f=1,\dots,8,$$

$$s_t=\max_{f}\ \frac{\max\big(C^{+}_{f,t},\,C^{-}_{f,t}\big)}{h}.$$

与库版唯一的区别：递推从"标量 $\bar z$"变成"8 维向量 $\boldsymbol{z}_t$"，输出从"标量累积"变成"逐特征累积取最大"。**k、h 完全不变**。

**为什么有效**：

1. **方向抵消消失**：每个特征独立累积，功率升累积在 $C^+_{\text{power}}$，ratio 降累积在 $C^-_{\text{ratio}}$，谁也不抵消谁；
2. **稀疏漂移不再稀释**：位置推送只漂移码相位族 2–3 个特征，它们的累积独占整条跑道，max 取出最强证据——每帧 $(\delta_f-k)^+$ 的速度不被其他特征拖累；
3. **保留 CUSUM 的全部优点**：重置免疫噪声（虚警零）、无界累积（任意慢的漂移最终可检）。

## 14.4 源码怎么实现

```python
class MCUSUM:
    def __init__(self, k=0.5, h=5.0): ...
    def _run(self, Z):
        cp = np.zeros(Z.shape[1]); cm = np.zeros(Z.shape[1])   # 8 条跑道的两个方向
        s = np.empty(len(Z))
        for i in range(len(Z)):
            cp = np.maximum(0.0, cp + Z[i] - self.k)           # 逐特征递推（向量化）
            cm = np.maximum(0.0, cm - Z[i] - self.k)
            s[i] = np.maximum(cp, cm).max() / self.h           # 取最强跑道
        return s
    def fit(self, Z): return self    # 无参数要学（标准化在驱动层）
```

与库版 CUSUM 的代码差异：`z[i].mean()` → `Z[i]`（向量），`max(cp,cm)` → `max(cp,cm).max()`（跨特征）。**又是单变量消融。**

## 14.5 改进的效果（实测，本系列最重要的数字）

- **宏平均：AUC 0.9919（全场最高，6 个场景满分）、三档实际虚警全场景精确 0.0000、1% 档 0.875**；
- **ds3（最难的位置推送）：0.284 → 0.919@零虚警**——逐特征累积抓到了均值聚合抵消掉的码相位族漂移（ADD 20.78 秒，累积需要时间）；
- **ds6（sophisticated）：0.583 → 0.939@零虚警**——接管后的残余微漂移是它的主场；
- **已知弱点**：动态场景（ds4）运动噪声频繁重置累积，ADD 96 秒——"抓得稳但慢"。

**对照表（单变量消融证据链）**：

| | 库版 CUSUM | MCUSUM | 变化 |
|---|---|---|---|
| 宏 AUC | 0.902 | 0.992 | +0.09 |
| 宏 1% 档 | 0.744 | 0.875 | +0.13 |
| ds3 1% 档 | 0.284 | 0.919 | +0.64 |

## 14.6 小结

MCUSUM 是"最小改动、最大收益"的教科书：**只把"先均值"改成"先逐特征、再取最大"，最难场景的检出翻了三倍**。它证明了：在多元 CUSUM 里，"聚合方式"比"累积算法"本身更关键——方向抵消是比噪声更可怕的敌人。

# 第 15 篇：margin 与 OR——融合的第一课

**对应结果目录**：`results/fusion/or3_EWMA+MEWMA+MCUSUM/`　**源码**：`run_fusion_v31.py` 搜索循环

## 15.1 第一个问题：三个分数不能直接比较

EWMA 的分数≈z 幅度（0 到几），MEWMA 的分数≈卡方型二次型（几十到几百），MCUSUM 的分数≈越限倍数（0 到几百）。**量纲和分布完全不同**，直接 `max` 或 `mean` 会被"分布最宽"的成员主导。

**解法：margin 归一化**。对每个成员，用它的**清洁训练分数**的两个分位做锚点：

$$m_i(t)=\frac{s_i(t)-q_{i,99}}{q_{i,99.9}-q_{i,99}},$$

$q_{i,99}$ 是成员 $i$ 训练分数的第 99 分位（即它自己的 1% 档阈值），$q_{i,99.9}$ 是 99.9 分位。于是：

| $m_i(t)$ 取值 | 含义 |
|---|---|
| $\le 0$ | 成员 $i$ 没超过自己的 1% 阈值（不告警） |
| $0 < m_i < 1$ | 成员 $i$ 在 1% 档告警 |
| $\ge 1$ | 成员 $i$ 超过自己的 0.1% 阈值（强告警） |

**margin 的妙处**：(1) 所有成员统一到同一语义——"$m_i>0$ 就是 1% 档告警"；(2) 锚点全部来自清洁数据（零泄漏）；(3) 对成员的仿射变换不敏感（$s_i\to as_i+b$ 不影响 margin）——成员内部怎么标准化无所谓。

**直觉**：margin 是"用每个人自己的尺子量自己超了多少"——高个子和矮个子比"超过自己身高的百分比"，而不是比绝对身高。

## 15.2 第二个问题：怎么组合——答案是 max（OR）

$$F(t)=\max_i m_i(t).$$

**为什么 max 就是 OR**：告警事件 $\{F\ge\tau\}=\bigcup_i\{m_i\ge\tau\}$——融合告警 = 成员告警的**并集**。特别地，1% 档阈值设 0：

$$\text{报警} \iff \text{至少一个成员在自己的 1\% 档告警}.$$

**为什么 OR 不会更差（单调性定理）**：如果成员 $j$ 在某帧告警（$m_j>0$），那 $F\ge m_j>0$，融合也告警。所以**融合的检出率 ≥ 任何一个成员的检出率**——OR 不会比最强成员差。

**那 OR 的增益从哪来**？来自**告警帧不重叠**：EWMA 覆盖攻击头部，MCUSUM 覆盖接管后尾部，头部帧只有 EWMA 告警、尾部帧只有 MCUSUM 告警——并集 > 任一成员。实测 ds3：三成员 1% 档分别 0.399/0.327/0.919，OR 后 **1.000**。

**那虚警会不会爆炸**？并集虚警率 ≤ 各成员虚警率之和。但实测三成员 1% 档实际虚警 0.0089/0.0051/0.0000，融合 0.0089 ≈ 最大值而非三者之和——因为**在清洁段三个成员高度正相关**（正常帧都不告警），并集不会显著放大虚警。

## 15.3 为什么不能简单平均（反面对照）

同一批成员用 `mean` 融合：1% 档宏平均 <0.89（搜索结果），明显低于 or3 的 0.9614。为什么？平均把"只有单个成员告警"的强证据稀释了——EWMA 单独抓到的头部帧，被 MEWMA/MCUSUM 的 0 分平均后掉到阈值以下。**平均是"和稀泥"，OR 是"谁有证据谁说了算"**。

## 15.4 三档阈值怎么定

| 档位 | 阈值 | 语义 |
|---|---|---|
| 1% | $\tau_1=0$ | **精确成员级 OR**（任一成员 1% 档告警即报警） |
| 5% | $\tau_5=q_{95}(F_{\text{train}})$ | 融合分数自身的清洁 95 分位 |
| 10% | $\tau_{10}=q_{90}(F_{\text{train}})$ | 融合分数自身的清洁 90 分位 |

1% 档用 0 是因为"$m_i>0$"有精确语义；5%/10% 档没有类似解析锚点，退化为融合分数的分位数（工程近似）。

## 15.5 成员为什么选这三个（互补性论证）

| 成员 | 时间结构 | 独门武功 | 代表场景 |
|---|---|---|---|
| EWMA | 5 帧记忆 | 快（ADD 亚秒）、阶跃/畸变 | ds1/ds4/ds5 |
| MEWMA | 5 帧记忆+协方差 | 虚警纪律（0.005） | ds8（0.971@0） |
| MCUSUM | 无界累积 | 慢漂移全覆盖（ds3 0.92） | ds3/ds6 |

三者两两互补：EWMA vs MEWMA = 度量互补（绝对值均值 vs 方向二次型）；EWMA/MEWMA vs MCUSUM = **时间尺度互补**（瞬态 vs 累积）。这就是"Tri-channel Temporal"（三通道时间互补）的含义。

## 15.6 小结

融合的两课：**margin 把异质分数统一到同一语义，OR 让互补证据并集叠加**。下一篇把这一切正式命名，并给出完整的数学原理（包括为什么检出有下界、虚警有上界、误差怎么归因）。

# 第 16 篇：TMOF——正式命名与完整原理

**对应结果目录**：`results/fusion/or3_EWMA+MEWMA+MCUSUM/`　**完整文档**：`18_TMOF_分层边际OR融合.md`（504 行，含全部数学推导）

## 16.1 命名

**TMOF = Tiered Margin-OR Fusion（分层边际 OR 融合）**，全称 Tri-channel Temporal Margin-OR Fusion（三通道时间互补的分层边际 OR 融合）。逐词含义：

- **Tiered（分层）**：三档阈值各自构造（1% 精确 OR，5%/10% 分位）；
- **Margin（边际）**：清洁分位锚点的归一化（第 15 篇第一课）；
- **OR（或）**：max 并集决策（第 15 篇第二课）；
- **Tri-channel Temporal（三通道时间）**：EWMA/MEWMA/MCUSUM 三个时间结构互补的通道。

## 16.2 最终成绩（宏平均 8 场景）

| 指标 | **TMOF** | 最强单方法（EWMA） | 改进单方法（MCUSUM） |
|---|---|---|---|
| ROC-AUC | **0.9910** | 0.9845 | 0.9919 |
| TPR@1%（实际FPR） | **0.9614**（0.0089） | 0.8748（0.0089） | 0.8751（0.0000） |
| TPR@5% | **0.9759** | 0.9646 | 0.9092 |
| TPR@10% | **0.9805** | 0.9773 | 0.9163 |
| ADD | 7×亚秒 + ds7 52s | 同 | 2×>90s |

**对全部 16 个单方法的三档工作点支配**——1% 档 +8.7pt（虚警持平），5%/10% 档 +1.1/+0.3pt。

## 16.3 数学原理速览（完整推导见 TMOF 专档）

1. **检出下界（OR 单调性）**：$TPR_{\text{TMOF}}\ge\max_i TPR_i$——融合不会比最强成员差；
2. **检出力（并集覆盖）**：$P_D=\frac{1}{|\mathcal{S}|}\big|\bigcup_i\mathcal{A}_i\big|$，$\mathcal{A}_i$ 是成员告警帧集。成员在欺骗段**低重叠**（时间互补）时 $P_D\to\sum_i P_{D,i}$——ds3 的 $\sum=1.645$（三成员各自 0.40/0.33/0.92）但并集只能到 1.000，说明**帧级互补**而非帧级独立；
3. **虚警上界**：$P_{FA}\le\sum_i P_{FA,i}$；清洁段成员正相关时 $\approx\max_i P_{FA,i}$——实测 0.0089≈max(0.0089,0.0051,0.0)；
4. **误差归因**：漏检帧 = 三个成员**同时**漏的帧（$\bigcap_i(\mathcal{S}\setminus\mathcal{A}_i)$）。ds3 的归因显示：EWMA 单独覆盖 6900 帧头部、MCUSUM 单独覆盖 15893 帧（尾部），并集 17293=全覆盖——**头部帧只有瞬态通道能抓，尾部帧只有持续通道能抓**，互补性在帧级成立；
5. **渐近一致性**：训练足够大时，名义虚警收敛、检出收敛到 1（若并集覆盖）；动态场景的虚警超标（0.032–0.036）是唯一系统性偏离（清洁分布跨场景漂移）。

## 16.4 三个诚实的边界

1. **ds7（慢速时间调整）无增益**：三成员都弱（≤0.74）且告警帧重叠，OR 无法创造证据——需要新特征（如码-载波一致性）；
2. **动态场景 1% 档实际虚警 0.032–0.036** 略超名义——成员固有，需运动状态条件化修复；
3. **变体在测试集上选择**：455 个组合的择优用了测试集指标（无独立欺骗验证集的现实约束），正式报告需多种子重复。

## 16.5 小结

TMOF 是"融合方法论"的终点：**margin 统一量纲 → max 并集 → 分层阈值**，把三个互补的检测器变成一个"每个场景自动选择/拼接最优通道"的超级检测器。它的成功不是某个成员的功劳，而是**时间结构互补 + OR 并集**这两个设计的乘积。全文完。
