# 第 12 篇：传统方法库使用与私有数据集指南

> 本库在深度模型之外新增了 **24 个传统（统计/经典机器学习）方法**，放在 `method_lib/traditional/`。本文说明：①传统方法库怎么用；②你自己的私有数据集如何接入传统方法；③**每个方法对数据输入的具体要求**（形状、单/多变量、等长、周期、分布假设等）。
>
> 传统方法库**不改动**现有 `run.py / exp / data_provider / model` 接口，深度模型照常使用；传统方法通过独立入口 `tools/run_traditional.py` 调用。

---

## 1. 传统方法库总览

命名规则：`<方法>_<SingleVar|MultiVar>_<适用条件>.py`

- `SingleVar`：单变量（一元时间序列）方法；
- `MultiVar`：多变量（多元时间序列）方法；
- 最后一段描述适用条件，例如 `StationaryLinear`（平稳线性）、`Seasonal`（有季节）、`Online`（适合在线）、`SmallData`（小样本）。

### 1.1 预测（9 个）

| 方法 | 单/多 | 适用条件 |
|---|---|---|
| Naive_SingleVar_Baseline | 单 | 最基础下界基线 |
| NaiveSeasonal_SingleVar_Periodic | 单 | 有已知稳定周期 |
| ExponentialSmoothing_SingleVar_LevelTrend | 单 | 无季节、水平/趋势 |
| HoltWinters_SingleVar_Seasonal | 单 | 趋势 + 季节 |
| Arima_SingleVar_StationaryLinear | 单 | 差分后平稳、线性 |
| Sarima_SingleVar_Seasonal | 单 | 线性 + 季节 |
| KalmanLocalLevel_SingleVar_Online | 单 | 在线、随机游走+噪声 |
| Var_MultiVar_LinearInteractions | 多 | 变量少、线性交互 |
| Arimax_MultiVar_Exogenous | 多特征/单目标 | 目标 + 外生解释变量 |

### 1.2 分类（5 个）

| 方法 | 单/多 | 适用条件 |
|---|---|---|
| KnnDtw_SingleVar_SmallData | 单 | 小样本、时间错位、长度可不一 |
| KnnEd_SingleVar_Aligned | 单 | 等长已对齐、小样本 |
| FeatureRf_SingleVar_MediumData | 单 | 中样本、可解释、噪声稳健 |
| KnnDtw_MultiVar_ChannelFusion | 多 | 多通道小样本、时间错位 |
| FeatureRf_MultiVar_ChannelFusion | 多 | 多通道中样本、特征拼接+森林 |

### 1.3 异常检测（10 个）

| 方法 | 单/多 | 适用条件 |
|---|---|---|
| StatisticalThreshold_SingleVar_Gaussian | 单 | 近似正态、快速粗糙 |
| Cusum_SingleVar_Online | 单 | 在线、持续小幅漂移 |
| Ewma_SingleVar_Online | 单 | 在线、平滑噪声 |
| StlResidual_SingleVar_Seasonal | 单 | 强趋势+季节、尖峰异常 |
| Mahalanobis_MultiVar_Gaussian | 多 | 近似多元正态、变量相关 |
| PcaReconstruction_MultiVar_Correlated | 多 | 高维强相关 |
| HotellingT2_MultiVar_ProcessMonitoring | 多 | 过程监控、T²+SPE |
| IsolationForest_MultiVar_NonGaussian | 多 | 非高斯、大数据 |
| Lof_MultiVar_LocalDensity | 多 | 密度不均匀、局部异常 |
| OneClassSvm_MultiVar_Boundary | 多 | 小中样本、非线性边界 |

## 2. 统一入口怎么用

```bash
cd method_lib

# 预测
python tools/run_traditional.py --task forecast \
  --method Arima_SingleVar_StationaryLinear \
  --data ETTh1 --target OT --seq_len 96 --pred_len 96

# 异常检测
python tools/run_traditional.py --task anomaly \
  --method IsolationForest_MultiVar_NonGaussian \
  --data MSL --anomaly_ratio 1

# 分类
python tools/run_traditional.py --task classification \
  --method KnnDtw_SingleVar_SmallData \
  --data UEA --dataset UWaveGestureLibrary
```

结果写入 `result_traditional_forecast.txt` / `result_traditional_anomaly.txt` / `result_traditional_classification.txt`，同时终端打印。

常用参数：

| 参数 | 含义 |
|---|---|
| `--num_windows` | 预测评估时在测试段取的窗口数（默认 10） |
| `--anomaly_ratio` | 异常判定阈值百分比（默认 1） |
| `--season` | 周期长度（季节类方法） |
| `--arima_order` | ARIMA/SARIMA/ARIMAX 的 (p,d,q)，如 `2,1,2` |
| `--seasonal_order` | SARIMA 季节阶数 (P,D,Q,s)，如 `1,1,1,24` |
| `--var_maxlags` | VAR 滞后阶数 |
| `--pca_components` | PCA/T² 主成分数或解释比例 |
| `--max_train / --max_test` | 截断训练/测试样本数（加快验证） |

## 3. 私有数据集如何使用（按任务）

### 3.1 预测任务

数据文件与深度模型完全一致（见第 10 篇）：`dataset/<你的数据集>/xxx.csv`，格式为 `date,变量1,...,变量M,OT`。

```bash
# 单变量方法（自动只用 OT 列）
python tools/run_traditional.py --task forecast \
  --method Sarima_SingleVar_Seasonal \
  --data custom --root_path ../dataset/my_data/ --data_path temp.csv \
  --target OT --seq_len 96 --pred_len 96 --season 24

# 多变量方法（用全部变量列）
python tools/run_traditional.py --task forecast \
  --method Var_MultiVar_LinearInteractions \
  --data custom --root_path ../dataset/my_data/ --data_path temp.csv \
  --seq_len 96 --pred_len 96

# ARIMAX：CSV 中“最后一列是目标，其余列是外生变量”
python tools/run_traditional.py --task forecast \
  --method Arimax_MultiVar_Exogenous \
  --data custom --root_path ../dataset/my_data/ --data_path temp.csv \
  --target OT --seq_len 96 --pred_len 96
```

注意：

- 切分自动按 70/20/10；`--max_train/--max_test` 可截断；
- 单变量方法只取 `OT`（目标）列；多变量方法取全部变量列；ARIMAX 约定最后一列是目标；
- 传统方法在**原始尺度**上评估（不做标准化），便于直接读 MSE/MAE。

### 3.2 异常检测任务

文件约定与深度模型一致：PSM 用 `Train.csv/Test.csv/Test_label.csv`，MSL/SMAP/SMD 用 npy，SWAT 用 `swat_train2.csv/swat2.csv`（见第 10 篇 3 节）。

```bash
python tools/run_traditional.py --task anomaly \
  --method Mahalanobis_MultiVar_Gaussian \
  --data PSM --root_path ../dataset/my_anom/ \
  --anomaly_ratio 1
```

注意：

- 标签必须是 0/1；训练集用正常数据；
- 单变量方法对多列数据逐列独立检测后取平均分；多变量方法直接在多维空间打分；
- `--max_train/--max_test` 可截断（STL 等方法在大数据上较慢）。

### 3.3 分类任务

文件约定与深度模型一致：`dataset/<数据集名>/<数据集名>_TRAIN.ts` 与 `_TEST.ts`（见第 10 篇 4 节）。

```bash
python tools/run_traditional.py --task classification \
  --method KnnDtw_MultiVar_ChannelFusion \
  --data UEA --dataset MyClass
```

注意：

- 单变量方法（类名含 `SingleVar`）会自动**取第一通道**（如果样本是多通道）；
- 多变量方法使用全部通道；
- KnnEd 要求所有样本**等长**；KnnDtw 允许长度不同；
- 类别数与样本量自动从 `.ts` 文件统计。

## 4. 每个方法的数据输入要求

### 4.1 预测方法

| 方法 | 输入形状 | 单/多 | 关键要求 |
|---|---|---|---|
| Naive_SingleVar_Baseline | 一维 `[T]` | 单 | 按时间升序；无缺失 |
| NaiveSeasonal_SingleVar_Periodic | 一维 `[T]` | 单 | 需 `--season` 周期长度 |
| ExponentialSmoothing_SingleVar_LevelTrend | 一维 `[T]` | 单 | 无明显季节；无缺失 |
| HoltWinters_SingleVar_Seasonal | 一维 `[T]` | 单 | 需 `--season`；数据覆盖 ≥2 个周期 |
| Arima_SingleVar_StationaryLinear | 一维 `[T]` | 单 | 差分后近似平稳；线性；样本几百+ |
| Sarima_SingleVar_Seasonal | 一维 `[T]` | 单 | 需 `--season`；≥2~3 个季节周期 |
| KalmanLocalLevel_SingleVar_Online | 一维 `[T]` | 单 | 等间隔；随机游走+噪声假设 |
| Var_MultiVar_LinearInteractions | 二维 `[T,M]` | 多 | M 不宜过大（<10）；平稳或差分；无缺失 |
| Arimax_MultiVar_Exogenous | 二维 `[T,M]` | 多特征单目标 | 最后一列为目标，其余为外生；线性 |

### 4.2 分类方法

| 方法 | 输入形状 | 单/多 | 关键要求 |
|---|---|---|---|
| KnnDtw_SingleVar_SmallData | 样本列表，每样本一维 `[T_i]` | 单 | 长度可不同；样本量几十~几百 |
| KnnEd_SingleVar_Aligned | 样本列表，每样本一维 `[T]` | 单 | **必须等长、已对齐** |
| FeatureRf_SingleVar_MediumData | 样本列表，每样本一维 `[T_i]` | 单 | 内部重采样到 100；样本几百~几千 |
| KnnDtw_MultiVar_ChannelFusion | 样本列表，每样本二维 `[T_i,M]` | 多 | 长度可不同；M 为通道数 |
| FeatureRf_MultiVar_ChannelFusion | 样本列表，每样本二维 `[T_i,M]` | 多 | 每通道提特征后拼接；中样本 |

说明：入口对 `SingleVar` 方法会自动把多通道样本取第一通道；分类标签统一为整数（内部自动编码）。

### 4.3 异常检测方法

| 方法 | 输入形状 | 单/多 | 关键要求 |
|---|---|---|---|
| StatisticalThreshold_SingleVar_Gaussian | 二维 `[N,M]` | 单（逐列） | 近似正态；无强趋势 |
| Cusum_SingleVar_Online | 二维 `[N,M]` | 单（逐列） | 在线；检测小幅均值漂移 |
| Ewma_SingleVar_Online | 二维 `[N,M]` | 单（逐列） | 在线；平滑噪声 |
| StlResidual_SingleVar_Seasonal | 二维 `[N,M]` | 单（逐列） | 需 `--season`；长度 >2 个周期；有趋势+季节 |
| Mahalanobis_MultiVar_Gaussian | 二维 `[N,M]` | 多 | 近似多元正态；维度不宜过高 |
| PcaReconstruction_MultiVar_Correlated | 二维 `[N,M]` | 多 | 变量强相关；高维可用 |
| HotellingT2_MultiVar_ProcessMonitoring | 二维 `[N,M]` | 多 | 过程监控；多元正态近似 |
| IsolationForest_MultiVar_NonGaussian | 二维 `[N,M]` | 多 | 非高斯；大数据友好 |
| Lof_MultiVar_LocalDensity | 二维 `[N,M]` | 多 | 密度不均匀；样本量中等 |
| OneClassSvm_MultiVar_Boundary | 二维 `[N,M]` | 多 | 小中样本；非线性边界 |

统一约定：

- 训练集为正常数据 `X_train [N,M]`；测试集 `X_test [N_test,M]`；标签 `y_test` 为 0/1；
- 所有方法返回逐点异常分数（越大越异常），入口按 `--anomaly_ratio` 分位数定阈值；
- 单变量方法对每列独立打分后取各列平均，因此可直接接受多列数据；
- 数据无需提前标准化（部分方法内部自动标准化），缺失值请提前处理。

## 5. 端到端示例：自己的私有数据

假设你有一个 CSV `dataset/my_process/process.csv`（时间列 + 4 个传感器 + OT）：

```bash
# 1) 深度模型基线（Bi-FI）
python run.py --task_name long_term_forecast --is_training 1 --model Bi_FI \
  --model_id MyProcess_96 --data custom \
  --root_path ../dataset/my_process/ --data_path process.csv \
  --features M --freq h --seq_len 96 --label_len 48 --pred_len 96 \
  --enc_in 5 --dec_in 5 --c_out 5 --d_model 512 \
  --batch_size 32 --learning_rate 0.0001 --train_epochs 10

# 2) 传统方法基线（多变量 VAR）
python tools/run_traditional.py --task forecast \
  --method Var_MultiVar_LinearInteractions \
  --data custom --root_path ../dataset/my_process/ --data_path process.csv \
  --seq_len 96 --pred_len 96

# 3) 传统方法基线（单变量 SARIMA，只看 OT）
python tools/run_traditional.py --task forecast \
  --method Sarima_SingleVar_Seasonal \
  --data custom --root_path ../dataset/my_process/ --data_path process.csv \
  --target OT --seq_len 96 --pred_len 96 --season 24
```

异常检测/分类同理：按第 3.2/3.3 节放好文件，换 `--task` 与 `--method` 即可。最后用：

```bash
python tools/collect_results.py --out results_summary.json
```

汇总深度模型结果；传统方法结果在各 `result_traditional_*.txt` 中。

## 6. 常见问题

**Q1：我的数据是多通道，但想用 SingleVar 方法？**
入口会自动取第一通道；如果你希望用某一指定通道，可先预处理成单通道 `.ts` 或 CSV 目标列。

**Q2：KnnEd 报长度不一致？**
KnnEd 要求等长；改用 KnnDtw（允许长度不同）或先把数据重采样到等长。

**Q3：STL 报错/很慢？**
序列长度需大于 2 个季节周期；大样本用 `--max_train/--max_test` 截断。

**Q4：异常检测的 F1 很低？**
传统点级方法在 1% 阈值下精度/召回通常低于深度重建方法；可调 `--anomaly_ratio`，或使用更适合分布假设的方法（正态→马氏/PCA；非高斯→IF/LOF）。

**Q5：传统方法结果与深度模型结果能直接比吗？**
可以比趋势，但注意协议不同：传统方法预测在原始尺度、窗口数有限；深度模型在标准化尺度、全量测试。建议固定 `--num_windows` 与 `--pred_len` 后再对比。
