# 第 11 篇：数据预处理全流程与代码解析

> 本文把“从原始数据到模型输入”的完整流水线拆开，逐步讲解每一步做了什么、为什么这么做，并**逐段解析本库 `data_provider/data_loader.py` 与 `data_provider/uea.py` 中的真实代码**。最后给出“私有数据集做完后如何端到端使用”的完整示例。

---

## 1. 全流程总览

无论哪个任务，数据从磁盘到模型都要经过下面这条流水线：

```text
原始文件（CSV / txt / npy / .ts）
        │
        ▼
① 读取与列整理      —— 读文件、去掉/重排时间列和目标列
        │
        ▼
② 切分              —— 按 70/20/10 或固定边界分成 train / val / test
        │
        ▼
③ 标准化            —— 只用训练集统计量做 StandardScaler
        │
        ▼
④ 时间特征构造      —— 从时间戳提取月/日/星期/小时/分钟
        │
        ▼
⑤ 滑窗取样          —— __getitem__ 按 seq_len/label_len/pred_len 取窗口
        │
        ▼
⑥ DataLoader 打包   —— batch、shuffle、drop_last、num_workers
        │
        ▼
模型输入 X ∈ R^{B×T×M}（分类还会带 padding_mask）
```

下面以 **预测任务（`Dataset_Custom`）** 为主线逐段解析，再说明异常检测与分类的不同之处。

## 2. 预测任务预处理源码解析

### 2.1 初始化：记住参数

```python
class Dataset_Custom(Dataset):
    def __init__(self, root_path, flag='train', size=None,
                 features='S', data_path='ETTh1.csv',
                 target='OT', scale=True, timeenc=0, freq='h'):
        # size [seq_len, label_len, pred_len]
        if size == None:
            self.seq_len = 24 * 4 * 4      # 默认 384
            self.label_len = 24 * 4        # 默认 96
            self.pred_len = 24 * 4         # 默认 96
        else:
            self.seq_len = size[0]         # 输入长度 T
            self.label_len = size[1]       # 起始标签长度
            self.pred_len = size[2]        # 预测长度 H

        assert flag in ['train', 'test', 'val']
        type_map = {'train': 0, 'val': 1, 'test': 2}
        self.set_type = type_map[flag]
```

解析：

- `size=[seq_len, label_len, pred_len]` 由 `run.py` 的 `--seq_len/--label_len/--pred_len` 传入；
- `flag` 决定当前是训练/验证/测试，映射成数字 `set_type ∈ {0,1,2}`，后面用来选切分边界；
- `features='M'` 表示“多变量预测多变量”；`target='OT'` 是目标列名。

### 2.2 读取与列整理

```python
    def __read_data__(self):
        self.scaler = StandardScaler()
        df_raw = pd.read_csv(os.path.join(self.root_path, self.data_path))

        cols = list(df_raw.columns)
        cols.remove(self.target)          # 去掉目标列名
        cols.remove('date')               # 去掉时间列名
        df_raw = df_raw[['date'] + cols + [self.target]]   # 重排：date 在最前，target 在最后
```

解析：

- `pd.read_csv` 一次性把整个 CSV 读进内存；
- 代码要求 CSV 里**必须有名为 `date` 的列**和**名为 `OT`（或 `--target` 指定）的列**；
- 重排后列顺序固定为 `[date, 变量1, 变量2, …, OT]`，这样后面的“去掉第一列就是全部变量”成立。

> 常见报错：`KeyError: 'OT'` 就是 CSV 里没有 `OT` 列；`KeyError: 'date'` 就是时间列不叫 `date`。

### 2.3 切分边界（70/20/10）

```python
        num_train = int(len(df_raw) * 0.7)
        num_test = int(len(df_raw) * 0.2)
        num_vali = len(df_raw) - num_train - num_test
        border1s = [0, num_train - self.seq_len, len(df_raw) - num_test - self.seq_len]
        border2s = [num_train, num_train + num_vali, len(df_raw)]
        border1 = border1s[self.set_type]
        border2 = border2s[self.set_type]
```

解析：

- 训练集：行 $[0,\ \text{num\_train})$；
- 验证集：行 $[\text{num\_train},\ \text{num\_train}+\text{num\_vali})$；
- 测试集：行 $[\text{len}-\text{num\_test},\ \text{len})$；
- 每个区间的起点都**往前多留 `seq_len` 行**（`border1 = ... - seq_len`），因为构造窗口样本时需要前面 `seq_len` 步作输入，否则区间开头没有历史可看；
- 也就是说：切分粒度是“行”，你只要保证数据按时间排序即可，代码自动切分。

### 2.4 标准化（只用训练集统计量）

```python
        if self.features == 'M' or self.features == 'MS':
            cols_data = df_raw.columns[1:]      # 去掉 date，取全部变量
            df_data = df_raw[cols_data]
        elif self.features == 'S':
            df_data = df_raw[[self.target]]     # 单变量：只取目标列

        if self.scale:
            train_data = df_data[border1s[0]:border2s[0]]   # 只取训练区
            self.scaler.fit(train_data.values)              # 在训练集上估计均值/方差
            data = self.scaler.transform(df_data.values)    # 对全部数据做变换
        else:
            data = df_data.values
```

对应的数学：

$$
z=\frac{x-\mu_{\text{train}}}{\sigma_{\text{train}}}
$$

解析：

- 用 `sklearn.preprocessing.StandardScaler`；
- **关键点：`fit` 只在训练区做**（`border1s[0]:border2s[0]`），避免验证/测试信息泄露；
- `transform` 作用于全部数据，保证三个集合使用同一套 $\mu,\sigma$；
- 模型输出是标准化尺度，评测前用 `inverse_transform`（或模型内的反归一化）还原。

### 2.5 时间特征构造

```python
        df_stamp = df_raw[['date']][border1:border2]        # 只取本集合的时间戳
        df_stamp['date'] = pd.to_datetime(df_stamp.date)
        if self.timeenc == 0:
            df_stamp['month'] = df_stamp.date.apply(lambda row: row.month, 1)
            df_stamp['day'] = df_stamp.date.apply(lambda row: row.day, 1)
            df_stamp['weekday'] = df_stamp.date.apply(lambda row: row.weekday(), 1)
            df_stamp['hour'] = df_stamp.date.apply(lambda row: row.hour, 1)
            data_stamp = df_stamp.drop(['date'], 1).values
        elif self.timeenc == 1:
            data_stamp = time_features(pd.to_datetime(df_stamp['date'].values), freq=self.freq)
            data_stamp = data_stamp.transpose(1, 0)
```

解析：

- `timeenc=0`：手写提取月、日、星期、小时（`timeF` 之外的老式做法）；
- `timeenc=1`（`--embed timeF` 时默认）：调用 `utils/timefeatures.py` 的 `time_features`，按 `--freq` 生成特征，例如小时级 `freq='h'` 会生成 4 维（月、日、星期、小时），分钟级 `freq='t'` 生成 5 维（多了分钟）；
- 这些时间特征会拼进嵌入层（第 0 篇的 `TimeFeatureEmbedding`），帮助模型利用周期性。

### 2.6 滑窗取样 `__getitem__`

```python
    def __getitem__(self, index):
        s_begin = index
        s_end = s_begin + self.seq_len                       # 输入窗口 [s_begin, s_end)
        r_begin = s_end - self.label_len
        r_end = r_begin + self.label_len + self.pred_len     # 标签窗口

        seq_x = self.data_x[s_begin:s_end]                   # 输入 X
        seq_y = self.data_y[r_begin:r_end]                   # 标签 Y（含 label_len 起始段 + H 预测段）
        seq_x_mark = self.data_stamp[s_begin:s_end]          # 输入时间戳
        seq_y_mark = self.data_stamp[r_begin:r_end]          # 标签时间戳
        return seq_x, seq_y, seq_x_mark, seq_y_mark

    def __len__(self):
        return len(self.data_x) - self.seq_len - self.pred_len + 1
```

解析：

- 每个样本是“滑窗”：输入 `seq_x` 是连续 `seq_len` 行，标签 `seq_y` 是从 `s_end - label_len` 到 `s_end + pred_len` 的行（前 `label_len` 步是已知真实值，后 `pred_len` 步是预测目标）；
- 总样本数 = 总行数 − seq_len − pred_len + 1，即最后一个完整窗口；
- 返回四个张量：输入值、标签值、输入时间特征、标签时间特征——这就是模型 `forward(x_enc, x_mark_enc, x_dec, x_mark_dec)` 收到的前两个（`x_dec` 由训练框架根据 `label_len` 拼零构造）。

### 2.7 ETT 与 Solar 的差别

`Dataset_ETT_hour`（ETTh1/ETTh2）与 `Dataset_Custom` 几乎一样，唯一区别是切分边界：

```python
        border1s = [0, 12 * 30 * 24 - self.seq_len, 12 * 30 * 24 + 4 * 30 * 24 - self.seq_len]
        border2s = [12 * 30 * 24, 12 * 30 * 24 + 4 * 30 * 24, 12 * 30 * 24 + 8 * 30 * 24]
```

即 ETT 用固定行数切分（12 个月训练、4 个月验证、4 个月测试），不是百分比。

`Dataset_Solar` 则直接从纯数值 txt 逐行读：

```python
        with open(os.path.join(self.root_path, self.data_path), "r", encoding='utf-8') as f:
            for line in f.readlines():
                line = line.strip('\n').split(',')
                data_line = np.stack([float(i) for i in line])
                df_raw.append(data_line)
        df_raw = np.stack(df_raw, 0)
```

它没有时间列，时间特征返回全零。

## 3. 异常检测预处理源码解析

以 PSM 加载器为例：

```python
class PSMSegLoader(Dataset):
    def __init__(self, root_path, win_size, step=1, flag="train"):
        ...
        data = pd.read_csv(os.path.join(root_path, 'Train.csv'))
        data = data.values[:, 1:]          # 去掉第一列（时间戳），只留特征
        data = np.nan_to_num(data)         # 缺失值填 0
        self.scaler.fit(data)              # 在训练集上标准化
        data = self.scaler.transform(data)
        test_data = pd.read_csv(os.path.join(root_path, 'Test.csv'))
        test_data = test_data.values[:, 1:]
        test_data = np.nan_to_num(test_data)
        self.test = self.scaler.transform(test_data)
        self.train = data
        data_len = len(self.train)
        self.val = self.train[(int)(data_len * 0.8):]        # 后 20% 作验证
        self.test_labels = pd.read_csv(os.path.join(root_path, 'Test_label.csv')).values[:, 1:]
```

解析：

- 异常检测**没有按 70/20/10 切分**：`Train.csv` 整体是训练集，验证集 = 训练集后 20%，测试集是 `Test.csv`；
- 标准化只用 `Train.csv` 的统计量，测试数据用同一套 scaler 变换；
- 滑窗在 `__getitem__` 中：训练/验证/测试都取 `win_size`（即 `--seq_len`）长度的窗口；
- 训练阶段返回的标签是测试标签的前 `win_size` 个（训练时不用标签，只是占位）；
- 异常分数 = 重建误差（模型输出与输入之差的平方），阈值由 `--anomaly_ratio` 在训练+测试误差的分位数上确定。

MSL/SMAP/SMD 加载器完全一样，只是把 CSV 换成 `.npy`：

```python
        data = np.load(os.path.join(root_path, "MSL_train.npy"))
        ...
        self.test_labels = np.load(os.path.join(root_path, "MSL_test_label.npy"))
```

SWAT 略有不同：

```python
        train_data = pd.read_csv(os.path.join(root_path, 'swat_train2.csv'))
        test_data = pd.read_csv(os.path.join(root_path, 'swat2.csv'))
```

## 4. 分类（UEA .ts）预处理源码解析

### 4.1 解析 .ts 文件

```python
def _parse_uea_ts(path):
    samples, labels, in_data = [], [], False
    with open(path, "r", encoding="utf-8", errors="replace") as f:
        for raw in f:
            line = raw.strip()
            if not line:
                continue
            if line.startswith("@") or line.startswith("#"):
                if line.lower().startswith("@data"):
                    in_data = True          # 从 @data 之后开始读样本
                continue
            if not in_data:
                continue
            if "(" in line:                  # 括号格式
                channels = re.findall(r"\(([^)]*)\)", line)
                label_str = line[line.rfind(")") + 1:].strip().lstrip(":").strip()
            else:                            # 冒号分隔格式
                parts = line.split(":")
                label_str = parts[-1].strip()
                channels = parts[:-1] if len(parts) > 1 else [parts[0]]
            arrs = []
            for ch in channels:
                vals = []
                for v in ch.split(","):
                    v = v.strip()
                    if v in ("?", "NaN", "nan", ""):
                        vals.append(float("nan"))   # 缺失值 -> NaN
                    else:
                        vals.append(float(v))
                arrs.append(np.asarray(vals, dtype=np.float64))
            tlen = max(len(a) for a in arrs)
            mat = np.full((tlen, len(arrs)), np.nan, dtype=np.float64)
            for j, a in enumerate(arrs):
                mat[:len(a), j] = a
            samples.append(mat)
            labels.append(label_str)
    return samples, labels
```

解析：

- 逐行处理，`@data` 之前的元信息全部跳过；
- 支持两种写法：冒号分隔多通道（本库默认）和括号格式；
- 每个通道的数值 `,` 分隔，`?` 转成 `NaN`；
- 如果各通道长度不同，按最长通道 padding NaN；
- 标签先保留原始字符串，后面统一编码。

### 4.2 标签编码与样本存储

```python
        class_names = sorted(set(raw_labels))          # 所有类别
        code_map = {c: i for i, c in enumerate(class_names)}
        labels = np.asarray([code_map[l] for l in raw_labels], dtype=np.int64)   # 类别 -> 整数
        self.samples = [np.ascontiguousarray(x, dtype=np.float32) for x in samples]
        self.max_seq_len = max(x.shape[0] for x in self.samples)                 # 最长样本长度
        self.class_names = np.asarray(class_names)
```

### 4.3 批内 padding（collate_fn）

```python
def collate_fn(data, max_len=None):
    features, labels = zip(*data)
    lengths = [X.shape[0] for X in features]
    if max_len is None:
        max_len = max(lengths)
    X = torch.zeros(batch_size, max_len, features[0].shape[-1])
    for i in range(batch_size):
        end = min(lengths[i], max_len)
        X[i, :end, :] = features[i][:end, :]          # 短样本补零
    targets = torch.stack(labels, dim=0)
    padding_masks = padding_mask(torch.tensor(lengths), max_len=max_len)
    return X, targets, padding_masks
```

解析：

- 一个 batch 内样本长度不同，统一 pad 到最长；
- `padding_masks` 标记哪些位置是真实数据（1）、哪些是填充（0），模型用它把填充位置清零（如 Informer/Autoformer 的 `output * x_mark_enc.unsqueeze(-1)`）；
- 返回 `(X, targets, padding_masks)`，与 `exp_classification.py` 的接口对应。

## 6. 预处理注意事项速查

1. **标准化**：本库在数据集内完成，你不需要提前归一化；但要保证训练集覆盖正常分布（不要用只含极端日期的数据训练）；
2. **缺失值**：预测 CSV 请提前插值/删除；分类 `.ts` 用 `?` 会被转 NaN；异常 CSV 会 `nan_to_num` 填 0（慎用，0 可能改变分布）；
3. **时间列**：预测数据必须有可解析的时间列；Solar 除外；
4. **切分**：预测按 70/20/10 自动切，异常按 Train/Test 文件切，分类按 `_TRAIN.ts/_TEST.ts` 切；
5. **变量数**：`--enc_in` 必须等于变量列数（预测不含 date；异常不含时间戳/标签；分类自动推断）；
6. **频率**：`--freq` 与时间特征维度绑定（h→4 维、t→5 维等），别乱填。
